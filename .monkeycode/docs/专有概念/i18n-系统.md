# i18n 多语言系统

## 架构概览

ZenTools 的国际化系统采用**两层字典 + 统一引擎**架构，支持 4 种语言。

```
┌────────────────────────────────────────────────────────┐
│                    用户选择语言                          │
│                  (#langSelect change)                   │
└─────────────────────┬──────────────────────────────────┘
                      │
                      ▼
┌────────────────────────────────────────────────────────┐
│                  ZT.applyLanguage(lang)                 │
│                    (tool-ui.js)                         │
│                                                        │
│  合并: ZT_COMMON[lang]  ←── 公共翻译 (common-i18n.js)   │
│         ZT_PAGE[lang]   ←── 页面翻译 (页面内联)         │
│                                                        │
│  应用: [data-i18n] textContent                          │
│        [data-i18n-placeholder] placeholder              │
│        document.title                                   │
│        #langSelect 选项文字                              │
│        localStorage.zentools_lang                       │
└────────────────────────────────────────────────────────┘
```

## 两层字典设计

### 第一层: `ZT_COMMON` (公共翻译)

`assets/js/common-i18n.js` 定义，包含全站通用 UI 文本:

- 导航链接: Home, All Tools, Categories
- 搜索占位符
- 页脚: Privacy, Terms, Contact
- 面包屑: Home
- 主题切换标签
- 语言选择器选项文字

```javascript
window.ZT_COMMON = {
  zh: { "nav_home": "首页", ... },
  en: { "nav_home": "Home", ... },
  ja: { "nav_home": "ホーム", ... },
  vi: { "nav_home": "Trang chủ", ... }
};
```

### 第二层: `ZT_PAGE` (页面翻译)

每个工具页面内联定义，包含该页面专用的 UI 文本:

```html
<script>
window.ZT_PAGE = {
  zh: { "page_title": "PDF 压缩", "btn_compress": "压缩", ... },
  en: { "page_title": "PDF Compress", "btn_compress": "Compress", ... },
  ja: { "page_title": "PDF圧縮", "btn_compress": "圧縮", ... },
  vi: { "page_title": "Nén PDF", "btn_compress": "Nén", ... }
};
</script>
```

### 合并优先级

`ZT_PAGE` 的同名键会覆盖 `ZT_COMMON` 的同名键。这使得页面可以覆盖公共翻译 (例如某个页面可能需要不同的导航文案)。

## HTML 标记

```html
<!-- textContent 替换 -->
<span data-i18n="page_title">默认文本</span>

<!-- placeholder 替换 -->
<input data-i18n-placeholder="search_placeholder" placeholder="Search..." />

<!-- 旧版属性 (仍支持) -->
<span data-i18n-page="page_title">默认文本</span>
```

## 语言切换流程

```
用户点击 #langSelect 下拉框
       │
       ▼
tool-ui.js: initLang() 事件处理器
       │
       ├── 读取选中值 (zh/en/ja/vi)
       ├── 调用 ZT.applyLanguage(lang)
       │    ├── 合并字典
       │    ├── 更新 DOM
       │    └── 保存到 localStorage
       ├── 派发 zt-setlang 事件
       │    └── common-i18n.js 监听 → 再次应用翻译
       └── 派发 zt-langchange 事件
            └── 其他脚本可选监听
```

## 初始语言检测

```
页面加载
  ↓
1. localStorage.zentools_lang → 存在则使用
  ↓ 不存在
2. navigator.language → 取前2字符
   "zh" → zh
   "en" → en
   "ja" → ja
   "vi" → vi
   其他 → zh (fallback)
  ↓
3. applyLanguage(lang) 自动调用
```

## 翻译键命名规范

- 使用 `snake_case`
- 语义化: 描述用途而非内容
- 前缀分类: `nav_` (导航), `footer_` (页脚), `info_` (信息), `btn_` (按钮), `heading_` (标题)

## tools-data.json 中的 i18n

工具元数据也包含多语言字段，使用后缀命名:

| 模式 | 示例 | 说明 |
|------|------|------|
| `字段名` | `"PDF 合并"` | 中文 (默认) |
| `字段名__en` | `"PDF Merge"` | 英文 |
| `字段名__ja` | `"PDF結合"` | 日文 |
| `字段名__vi` | `"Hợp nhất PDF"` | 越南文 |

涉及的字段: `name`, `description`, `privacy`, `audience`, `useCases`, `limits`

## 新增语言支持

要添加新语言 (如韩语 `ko`)，需要:

1. 在 `ZT_COMMON` 中添加 `ko` 子对象
2. 在所有页面的 `ZT_PAGE` 中添加 `ko` 子对象
3. 在 `tools-data.json` 中为每个工具添加 `__ko` 后缀字段
4. 在 `#langSelect` 中添加 `<option value="ko">한국어</option>`
5. 在 `applyLanguage` 中添加 `ko` 的 `html[lang]` 映射
