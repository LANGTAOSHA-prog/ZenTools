# i18n 国际化引擎

## 概述

ZenTools 支持 zh/en/ja/vi 四种语言的运行时即时切换，无需重新加载页面。翻译数据分散在两个来源：`common-i18n.js`（公共翻译）和每个页面的 `window.ZT_PAGE`（页面专属翻译）。

## 翻译数据流

```
common-i18n.js (window.ZT_COMMON)
        │
        │  加载时注入全局
        ▼
    ┌───────────────┐
    │ ZT.applyLang() │
    │ (tool-ui.js)   │
    └───────┬───────┘
            │  合并：ZT_PAGE[key] 覆盖 ZT_COMMON[key]
            ▼
    window.ZT_PAGE (页内定义)
            │
            ▼
    document.querySelectorAll('[data-i18n]')
    document.querySelectorAll('[data-i18n-placeholder]')
```

## 翻译键分辨率

`ZT.applyLanguage(lang)` 执行时：
1. `dict = { ...ZT_COMMON[lang], ...ZT_PAGE[lang] }` — 页面级键覆盖公共键
2. 遍历 `[data-i18n="key"]` — 替换 `textContent`
3. 遍历 `[data-i18n-placeholder="key"]` — 替换 `placeholder`
4. 更新 `document.title`
5. 写入 `localStorage('zentools_lang')`
6. 派发 `zt-langchange` 自定义事件

## 页面集成

每个页面必须内联定义 `window.ZT_PAGE`，包含四种语言的翻译：

```js
window.ZT_PAGE = {
  zh: { pageTitle: 'PDF 合并', step1: '选择文件', ... },
  en: { pageTitle: 'PDF Merge', step1: 'Select files', ... },
  ja: { pageTitle: 'PDF 結合', step1: 'ファイル選択', ... },
  vi: { pageTitle: 'Gộp PDF', step1: 'Chọn tệp', ... }
};
```

Fallback 文字必须与 `ZT_PAGE` 中对应 key 的值一致。

## 公共翻译范围

`common-i18n.js` 中的 `window.ZT_COMMON` 包含以下全局 key：
- 导航栏：`navHome`, `navAll`, `navSearch`, `navPlaceholder`
- 面包屑：`crumbHome`, `crumbAllTools`
- 页脚：`footAbout`, `footContact`, `footPrivacy`
- 语言选择器：`langZh`, `langEn`, `langJa`, `langVi`
- 搜索：`searchTitle`, `searchDesc`, `searchPlaceholder`, `searchNoResults`, `searchTotal`

## 事件监听

语言切换后需要重新渲染动态内容的组件，应在 `zt-langchange` 事件中处理：

```js
window.addEventListener('zt-langchange', function(e) {
  var lang = e.detail.lang;
  var dict = e.detail.dict;
  // 重新渲染动态生成的内容
  renderCards(lang);
});
```

## 初始加载

1. 页面加载时，`tool-ui.js` 的 `initLang()` 从 localStorage 读取 `zentools_lang`
2. 若未设置，默认为 `zh`
3. 调用 `ZT.applyLanguage(savedLang)` 应用翻译
4. 检查 URL hash（`#lang=en`）作为后备

## 注意事项

- 所有用户可见文本必须通过 `data-i18n` 标记，不得硬编码中英文
- 新页面必须包含完整的四语言 `ZT_PAGE` 定义
- 语言切换不依赖后端，纯前端运行时切换
- URL 路径不含语言前缀（非 `/zh/pdf-merge.html`）
