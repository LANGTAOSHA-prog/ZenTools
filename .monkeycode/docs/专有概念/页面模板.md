# 页面模板

ZenTools 存在**两种**工具页面模板。应统一使用新版模板。

## 新版模板 (tool-ui 模式)

以 `pdf/pdf-compress.html`、`dev/diff.html` 为代表。所有新工具必须使用此模式。

### 特征

- 通过 `<link>` 加载 `tool-ui.min.css` (统一样式)
- 通过 `<script>` 加载 `common-i18n.min.js` 和 `tool-ui.min.js` (统一运行时)
- 标准 `<nav>` 导航栏 (含全局搜索、语言选择器)
- `.page-header` 头部 (面包屑 + 渐变标题 + 描述)
- `.tool-box` 工具容器
- `.section` + `.info-grid` 说明区 (3 列信息卡)
- `<footer>` 统一页脚
- `.blob` 浮动光晕背景
- `body::before` 噪点纹理
- `window.ZT_PAGE` 翻译字典 (snake_case 键名)
- Service Worker 注册
- Schema.org JSON-LD (FAQPage + WebApplication)

## 旧版模板 (全内联模式)

以 `image/image-compressor.html` 为代表。存在以下问题:

- 全部 CSS/JS 内联书写，页面文件冗长
- 无统一导航栏
- 无统一页脚
- 翻译对象使用 `window.pageTranslations` (键名与 `ZT_PAGE` 不同)
- 不加载 `tool-ui.js` / `common-i18n.js`
- 无全局搜索、收藏、最近使用等功能
- 无光晕背景、噪点纹理等视觉效果

### 迁移方案

1. 用新版模板骨架包裹现有内容 (导航、页眉、页脚)
2. 提取内联样式到 `<style>` 标签 (保留在页面内)
3. 将 `window.pageTranslations` 转换为 `window.ZT_PAGE` 格式
4. 添加 `common-i18n.min.js` + `tool-ui.min.js` 引用
5. 移除手动编写的导航/页脚代码
6. 将手动进度条替换为 `ZT.showProgress/hideProgress`
7. 添加 Service Worker 注册
8. 添加 Schema.org JSON-LD

## 加载差异对比

| 特性 | 新版 (tool-ui) | 旧版 (inline) |
|------|---------------|---------------|
| CSS | `tool-ui.min.css` + `<style>` | 全内联 `<style>` |
| JS | `common-i18n.min.js` + `tool-ui.min.js` + `<script>` | 全内联 `<script>` |
| 导航 | 标准 `<nav>` | 无 |
| 搜索 | 全局搜索 (自动注入) | 无 |
| 收藏 | 收藏按钮 (自动注入) | 浮动按钮 |
| 主题 | 主题切换 (自动注入) | 无 |
| 进度 | `ZT.showProgress()` | 手动 DOM |
| i18n | `ZT_PAGE` + `ZT_COMMON` | `pageTranslations` |
| PWA | SW 注册 | 部分页面 |
| SEO | FAQPage + WebApplication JSON-LD | 部分页面 |
