# 数据层架构

## 概述

ZenTools 采用数据驱动分类架构（ZT-DCA），所有工具元数据统一存储在 `data/tools-data.json` 中（约 666KB，13,000+ 行），作为唯一的真值来源（Single Source of Truth）。首页、分类页、搜索页均从该数据源动态渲染。

## 数据结构

### 分类定义

```json
"categories": [
  "AI工具", "图片工具", "PDF工具", "文本工具",
  "音频工具", "视频工具", "开发工具", "SEO工具",
  "生活助手", "金融工具", "JSON工具", "二维码工具", "综合工具"
]
```

分类名称用于：
1. 目录映射（中文名 → 英文目录名）
2. 首页分类 tab 过滤
3. 搜索结果的分类筛选

### 工具条目结构

## 首页渲染流程

```
1. 加载 assets/js/tools-data.js
      │  (包含 toolsDataJson 变量，来自 tools-data.json)
      ▼
2. main.js 读取 toolsDataJson
      │
      ├──→ renderFeaturedTools()     热门工具区
      ├──→ renderCategoryTabs()       分类 Tab
      └──→ renderSearch()             搜索建议
```

## 分类页渲染流程

```
1. 分类固定页（如 /pdf/index.html）
      │
      ▼
2. fetch('/data/tools-data.json')
      │
      ▼
3. 根据 category 字段过滤本分类工具
      │
      ▼
4. 渲染工具卡片网格（名称+描述+图标+URL）
```

## 搜索机制

`tool-ui.js` 全局搜索采用 fetch + 本地过滤，不依赖后端：

1. 首次搜索时，fetch `/data/tools-data.json` 并缓存到内存
2. 将用户输入与 `name`、`description` 和 `keywords` 做子串匹配
3. 搜索结果按分类分组展示

## JS 版数据同步

`tools-data.js` 由 `_sync_tools_data_js.py` 从 `tools-data.json` 自动生成：

```bash
python3 _sync_tools_data_js.py
```

生成的 `tools-data.js` 格式：
```js
var toolsDataJson = { "version": "2.2", "tools": [...], "categories": [...] };
```

这样首页可以直接通过 `<script>` 标签加载工具数据，无需额外的 fetch 请求。

## 注意事项

- `tools-data.json` 是唯一的真值来源，所有页面都从它读取
- 添加新工具必须同时更新 `tools-data.json` 和创建对应的 HTML 页面
- 不要在不同页面中硬编码工具列表，应使用 JSON 数据动态渲染
- JSON 修改后必须运行 `_check_json.py` 校验格式完整性
