# 毛玻璃主题设计系统

## 概述

ZenTools 采用**暗色毛玻璃 (Glassmorphism)** 视觉风格，通过 CSS 自定义属性驱动，提供统一的视觉体验。

## 设计原则

1. **深度感**: 多层半透明背景 + `backdrop-filter: blur()` 制造空间层次
2. **科技感**: 青/紫/粉渐变品牌色，浮动光晕动画
3. **轻量感**: 极深蓝黑底色 (`#06070d`)，半透明卡片漂浮其上
4. **纹理感**: SVG 噪点纹理覆盖层增强质感

## 色彩系统

```css
:root {
  /* 背景层 */
  --bg:       #06070d;     /* 极深蓝黑 — 宇宙底色 */
  --glass:    rgba(255,255,255,0.04);   /* 毛玻璃 — 半透明 */
  --glass-b:  rgba(255,255,255,0.08);   /* 毛玻璃悬停 */

  /* 品牌色 (渐变三色) */
  --cyan:     #00e5ff;     /* 主色 — 科技青 */
  --purple:   #a855f7;     /* 辅色 — 神秘紫 */
  --pink:     #f43f5e;     /* 辅色 — 活力粉 */

  /* 文字 */
  --text:     #f0f4ff;     /* 主文字 — 近白蓝 */
  --muted:    #6b7a9f;     /* 弱化文字 — 灰蓝 */

  /* 边框 */
  --border:   rgba(255,255,255,0.07);    /* 隐形边框 */
  --border-h: rgba(0,229,255,0.35);      /* 悬停发光边框 */

  /* 形状 */
  --r:        20px;        /* 统一圆角 */

  /* 光晕 (仅 tool-ui.css) */
  --glow-c:   0 0 40px rgba(0,229,255,0.18);
}
```

## 视觉层次

```
┌────────────────────────────────────┐
│  body::before (z-index: 1)         │ ← SVG 噪点纹理 (opacity: 0.035)
│  全屏覆盖，固定不随滚动             │
├────────────────────────────────────┤
│  .blob-1 / .blob-2 (z-index: 0)   │ ← 600px/500px 光晕球体
│  固定定位，requestAnimationFrame    │   blur(120px), opacity(0.10)
│  缓慢浮动动画                       │   cyan / purple 各一
├────────────────────────────────────┤
│  .z-wrap (z-index: 2)             │ ← 所有实际内容
│                                    │
│  ┌──────────────────────────────┐ │
│  │ nav (sticky, z-index: 100)   │ │ ← backdrop-filter: blur(24px)
│  │ 毛玻璃导航栏                   │ │   saturate(180%)
│  └──────────────────────────────┘ │
│                                    │
│  ┌──────────────────────────────┐ │
│  │ .tool-box                    │ │ ← backdrop-filter: blur(8px)
│  │ 毛玻璃工具容器                 │ │   background: var(--glass)
│  └──────────────────────────────┘ │
│                                    │
│  ┌──────────────────────────────┐ │
│  │ .info-card                   │ │ ← 半透明卡片
│  │ 信息卡片                       │ │   border: 1px solid var(--border)
│  └──────────────────────────────┘ │
└────────────────────────────────────┘
```

## 视觉效果实现

### 毛玻璃

```css
backdrop-filter: blur(24px) saturate(180%);
/* 只在支持 backdrop-filter 的浏览器上生效 */
/* 不支持时回退为普通半透明 background */
```

### 噪点纹理 (仅 tool-ui.css)

```css
body::before {
  content: '';
  position: fixed;
  inset: 0;
  z-index: 1;
  pointer-events: none;
  background-image: url("data:image/svg+xml,...fractalNoise...");
  opacity: 0.035;
}
```

### 浮动光晕动画

```javascript
function animBlob() {
  const t = Date.now() / 1000;
  // blob-1: 青色光晕，600px，正弦波动
  blob1.style.transform = `translate(
    ${Math.sin(t * 0.3) * 80}px,
    ${Math.cos(t * 0.2) * 60}px
  )`;
  // blob-2: 紫色光晕，500px
  blob2.style.transform = `translate(
    ${Math.cos(t * 0.25) * 100}px,
    ${Math.sin(t * 0.35) * 70}px
  )`;
  requestAnimationFrame(animBlob);
}
```

### 滚动渐入

```javascript
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.reveal').forEach(el => observer.observe(el));
```

### 骨架屏 Shimmer

```css
@keyframes shimmer {
  0% { background-position: -400px 0; }
  100% { background-position: 400px 0; }
}
.skeleton-card {
  background: linear-gradient(90deg,
    var(--glass) 0%,
    var(--glass-b) 50%,
    var(--glass) 100%
  );
  background-size: 800px 100%;
  animation: shimmer 1.5s infinite;
}
```

## 按钮系统

```css

  padding: 12px 28px;
  font-weight: 600;

/* 幽灵按钮 */

  background: transparent;
  border: 1px solid var(--border);
  border-radius: 999px;
  color: var(--text);
}
```

## 响应式

| 断点 | 布局变化 |
|------|---------|
| `max-width: 1024px` | 4 列 → 2 列; hero 双列 → 单列 |
| `max-width: 768px` | 导航搜索框缩小 |
| `max-width: 640px` | 2 列 → 1 列; 内边距压缩 |

## 暗色/亮色切换

`loader.js` 通过 `data-theme` 属性实现主题切换 (当前亮色主题覆盖不完整):

```javascript
function toggleTheme() {
  const next = cur === 'dark' ? 'light' : 'dark';
  document.documentElement.setAttribute('data-theme', next);
  localStorage.setItem('zentools_theme', next);
}
```

> 注意: 亮色主题的 CSS 变量覆盖目前不完整，以暗色模式为主要使用体验。
