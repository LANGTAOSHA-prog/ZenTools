# ZenTools 网站编写守则与注意事项

## 一、核心架构原则

| 原则     | 说明                                                                      |
| -------- | ------------------------------------------------------------------------- |
| 数据驱动 | `data/tools-data.json` 是唯一的工具数据源，首页/分类页/搜索页全从中读取，禁止多处重复维护 |
| 单工具单页面 | 每个工具有独立 HTML，按分类放在对应目录：`/pdf/merge.html`、`/image/compress.html`      |
| 纯前端     | 仅 HTML + CSS + Vanilla JS，无框架依赖，GitHub Pages / Cloudflare Pages 直接部署        |
| 本地优先   | 所有处理在浏览器本地完成，文件不上传服务器                                                |

---

## 二、目录结构规范

```
/data/tools-data.json         ← 工具数据（新增/修改工具优先改这里）
/assets/css/tool-ui.css       ← 工具页面通用样式
/assets/js/tool-ui.js         ← 工具页面通用 JS
/assets/js/main.js            ← 首页渲染逻辑
/assets/js/i18n.js            ← 国际化引擎
/pdf/                         ← PDF 工具
/image/                       ← 图片工具
/tutorials/                   ← 教程页面
```

---

## 三、多语言（i18n）注意事项 ⚠

- 所有 `data-i18n` 元素的后备文字（fallback text）**必须**与 `window.ZT_PAGE` 中对应 key 的值一致
- 新增翻译 key 时，必须在 **zh / en / ja / vi** 四种语言中都添加
- 语言切换通过 `zt-langchange` 自定义事件触发全页重新渲染，`langSelect` 的 change 事件必须：
  ```js
  localStorage.setItem('zentools_lang', lang);
  window.dispatchEvent(new CustomEvent('zt-langchange', { detail: { lang: lang } }));
  ```
- 静态 HTML 中的 `data-i18n` 元素用于导航、标题等固定文字
- 动态渲染的内容（统计条、记录卡片）使用 `dict.statTools` 等形式从 `ZT_PAGE` 取

---

## 四、统计条（Stats Bar）排版规范

当前采用 Grid 4 列等宽 + 卡片边框布局：
```css
.stats-bar {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  max-width: 620px;
  border: 1px solid var(--border);
  border-radius: 14px;
}
```
- 每项用不同颜色区分（青/紫/绿/橙）
- 移动端（≤640px）自动切换 2×2
- 教程数量通过 `fetch('/tutorials/')` 异步获取，失败时隐藏不报错

---

## 五、搜索框规范

- 实时下拉搜索：输入内容后弹出 `.search-dropdown`，显示图标+名称+描述+分类
- 支持 ↑ ↓ Enter Escape 键盘导航
- 清除按钮（✕）在有输入时显示，点击清空并关闭下拉
- 点击外部区域自动关闭

---

## 六、教程页面规范

- 教程列表在 `tutorials/index.html`，每个教程是一个 `.article-card`
- 教程正文以 `.article-body` 形式放在卡片下方，默认 `display: none`
- 通过 `toggleArticle(id)` 函数实现展开/收起
- 卡片添加 `article-card-clickable` 类和点击提示文字

---

## 七、常见踩坑（注意事项）

1. `edit_file` 匹配失败 → 该文件使用制表符缩进，且行尾为 `\r\n`。改用 Python 脚本做文本替换更可靠
2. CSS 修改后未生效 → 检查是否有内联 `<style>` 覆盖，首页样式全部在 `index.html` 的 `<style>` 块内，不是外部 CSS
3. 新增工具流程：创建页面 → 更新 `tools-data.json` → 自动出现在首页，无需修改首页代码
4. 搜索下拉依赖 `_toolsData` → 全局变量 `_toolsData` 在 `renderHome` 中赋值，搜索功能依赖它
5. 教程数量显示 → 异步 fetch `/tutorials/` 解析 DOM 计数，非 JSON 数据源
6. 防崩机制 → 项目有 `anti-crash.js` 兜底，`window.ZT_CRASH` 备用模式，修改时注意兼容

---

## 八、UI 风格统一

- 深色主题：背景 `#08090f` / `#0f172a`，毛玻璃效果（`backdrop-filter: blur()`）
- 卡片圆角：统一 `border-radius: 14px~22px`
- 配色：青色 `var(--cyan)`、紫色 `var(--purple)`、边框 `var(--border)`
- 导航：顶部固定栏 + 手机端侧滑菜单（`.mobile-drawer`）
- 工具卡片（`.mini-card`）：图标 + 名称 + 描述 + 颜色标签

---

## 九、SEO 与部署

- 每个页面必须包含 `title`、`meta description`、`h1`
- URL 使用语义化路径：`/pdf/merge.html`，避免查询参数
- 保持 GitHub Pages 兼容性，路径区分大小写
- `CNAME` 文件绑定自定义域名 `zentools.xyz`

---

> **一句话总结**：数据驱动 + 单工具页面 + 4 语 i18n + 本地优先 + 深色卡片 UI。所有修改尽量不动首页核心代码，改 JSON 和新增页面即可。
