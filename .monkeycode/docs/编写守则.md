# ZenTools 网站编写守则与注意事项

> 本文档整合了原始网站开发规范与 ZenTools 品牌开发守则 V1.0。**凡品牌相关规则（配色、字体、圆角、Logo、文案、暗黑模式、卡片样式等），以品牌开发守则为准；仅架构、数据流、i18n、SEO 等纯技术规范保留原始规则。**

---

## 一、品牌基础（优先级最高）

### 1. 品牌定位
- 品牌全称：**ZenTools**，不得简写、改名或混用旧名
- 定位：隐私优先、免费全能的本地在线工具平台
- 核心调性：干净极简、专业可靠、高效易用、科技柔和

### 2. 品牌色（CSS 变量体系）

所有页面必须使用以下 CSS 变量，禁止硬编码颜色值或引入新的主色调：

```css
:root {
    /* 品牌主色 */
    --zen-primary: #0066FF;
    --zen-secondary: #00C2B8;
    --zen-gradient: linear-gradient(135deg, #0066FF, #00C2B8);

    /* 状态辅助色 */
    --zen-success: #22C55E;
    --zen-warning: #F97316;
    --zen-danger: #EF4444;

    /* 浅色模式 */
    --zen-text-main: #111827;
    --zen-text-sub: #4B5563;
    --zen-text-placeholder: #9CA3AF;
    --zen-bg-base: #F9FAFB;
    --zen-bg-card: #FFFFFF;
    --zen-border: #E5E7EB;

    /* 全局圆角 */
    --zen-radius-base: 12px;
    --zen-radius-card: 16px;
    --zen-radius-btn: 8px;
    --zen-radius-tag: 6px;
}

.dark {
    --zen-text-main: #F9FAFB;
    --zen-text-sub: #D1D5DB;
    --zen-text-placeholder: #64748B;
    --zen-bg-base: #0F172A;
    --zen-bg-card: #1E293B;
    --zen-border: #334155;
}
```

- **渐变仅用于 Logo、主按钮、首页标题区域**，正文区域尽量用纯色减少性能消耗
- 正文文字对比度必须 >= 4.5:1
- 禁用旧的 `var(--cyan)`、`var(--purple)`、`var(--border)` 等变量，统一迁移至上述体系

### 3. 暗黑模式

- 同时支持浅色和暗黑两种模式，不可仅支持暗色
- 默认跟随系统设置 + 手动切换按钮，需要持久化用户偏好（localStorage）
- 暗黑模式下布局结构不变，仅替换配色变量
- Logo 在暗黑模式下使用纯白反白版或适配暗模式的渐变版

### 4. 字体规范

| 层级 | 字号 | 字重 | 字体 |
|------|------|------|------|
| H1 主标题 | 32px | 600/700 | Inter, 思源黑体 |
| H2 板块标题 | 24px | 600 | Inter, 思源黑体 |
| H3 卡片标题 | 18px | 600 | Inter, 思源黑体 |
| 正文 | 16px | 400/500 | Inter, PingFang SC, Microsoft YaHei |
| 辅助小字 | 14px | 400 | Inter, PingFang SC, Microsoft YaHei |
| 说明备注 | 12px | 400 | Inter, PingFang SC, Microsoft YaHei |

- 标题行高：1.2；正文行高：1.5
- 禁止引入花式艺术字体或衬线字体
- 英文/数字统一使用 Inter

### 5. Logo 规范

- 横版主 Logo：∞Z 图形 + ZenTools 标准字体（主站顶部、导航栏、页脚）
- 纯 Icon 版本：独立 ∞ 无限符号图标（favicon、App 图标）
- 禁止拉伸变形、修改渐变配色、替换字体、裁剪图形核心结构
- 网页端横版 Logo 最小高度 32px，纯 Icon 最小 24px
- 安全留白距离 = 图标高度的 1/4

### 6. UI 组件规范

**圆角基准**：全局 12px，大卡片 16px，按钮/输入框 8px，小标签 6px。禁止混用超大圆角或直角。

**按钮**：
- 主按钮：品牌渐变色底 + 白色文字 + 圆角 8px + padding 12px 24px，hover 轻微上浮
- 次要按钮：白色底 + 品牌色边框 + 品牌色文字
- 幽灵按钮：透明底 + 品牌色文字，hover 浅品牌色背景
- 禁用态：透明度降至 40%

**卡片**：
- 默认圆角 16px，细微柔和阴影
- 卡片内间距统一 20px
- 布局：图标 + 标题 + 简介，保持对齐
- 浅色模式白底 / 暗黑模式 `#1E293B` 底

**布局**：全局居中布局，最大宽度 1200px，固定栅格系统。

### 7. 文案规范

- 中文主标语：**专业在线工具平台 · 免费 · 高效 · 安全**
- 中文备选标语：**专业工具 · 无限可能**
- 英文主标语：**Professional Tools For Everyone**
- 核心信息反复强调：本地处理、文件不上传服务器、隐私安全、永久免费
- 页脚统一格式：`© [年份] ZenTools · https://zentools.xyz · All rights reserved`
- 语气：简洁、真诚、技术友好，拒绝夸张营销话术
- 海外文案：**I built ZenTools — A Free Privacy-First Online Tools Website**

## 二、核心架构原则

| 原则     | 说明                                                                      |
| -------- | ------------------------------------------------------------------------- |
| 数据驱动 | `data/tools-data.json` 是唯一的工具数据源，首页/分类页/搜索页全从中读取，禁止多处重复维护 |
| 单工具单页面 | 每个工具有独立 HTML，按分类放在对应目录：`/pdf/merge.html`、`/image/compress.html`      |
| 纯前端     | 仅 HTML + CSS + Vanilla JS，无框架依赖，GitHub Pages / Cloudflare Pages 直接部署        |
| 本地优先   | 所有处理在浏览器本地完成，文件不上传服务器                                                |

---

## 三、目录结构规范

```
/data/tools-data.json         ← 工具数据（新增/修改工具优先改这里）
/assets/css/tool-ui.css       ← 工具页面通用样式
/assets/js/tool-ui.js         ← 工具页面通用 JS
/assets/js/main.js            ← 首页渲染逻辑
/assets/js/common-i18n.js     ← 国际化引擎
/pdf/                         ← PDF 工具
/image/                       ← 图片工具
/tutorials/                   ← 教程页面
```

---

## 四、多语言（i18n）注意事项

- 所有 `data-i18n` 元素的后备文字（fallback text）必须与 `window.ZT_PAGE` 中对应 key 的值一致
- 新增翻译 key 时，必须在 **zh / en / ja / vi** 四种语言中都添加
- 语言切换通过 `zt-langchange` 自定义事件触发全页重新渲染，`langSelect` 的 change 事件必须：
  ```js
  localStorage.setItem('zentools_lang', lang);
  window.dispatchEvent(new CustomEvent('zt-langchange', { detail: { lang: lang } }));
  ```
- 静态 HTML 中的 `data-i18n` 元素用于导航、标题等固定文字
- 动态渲染的内容（统计条、记录卡片）使用 `dict.statTools` 等形式从 `ZT_PAGE` 取

## 五、搜索框规范

- 实时下拉搜索：输入内容后弹出 `.search-dropdown`，显示图标+名称+描述+分类
- 支持键盘导航（↑ ↓ Enter Escape）
- 清除按钮在有输入时显示，点击清空并关闭下拉
- 点击外部区域自动关闭

---

## 六、教程页面规范

- 教程列表在 `tutorials/index.html`，每个教程是一个 `.article-card`
- 教程正文以 `.article-body` 形式放在卡片下方，默认 `display: none`
- 通过 `toggleArticle(id)` 函数实现展开/收起
- 卡片添加 `article-card-clickable` 类和点击提示文字

---

## 七、常见踩坑（注意事项）

1. `edit_file` 匹配失败 → 该文件使用制表符缩进，且行尾为 `\r\n`。改用 Python 脚本做文本替换更可靠
2. CSS 修改后未生效 → 检查是否有内联 `<style>` 覆盖，首页样式全部在 `index.html` 的 `<style>` 块内，不是外部 CSS
3. 新增工具流程：创建页面 → 更新 `tools-data.json` → 自动出现在首页，无需修改首页代码
4. 搜索下拉依赖 `_toolsData` → 全局变量 `_toolsData` 在 `renderHome` 中赋值，搜索功能依赖它
5. 教程数量显示 → 异步 fetch `/tutorials/` 解析 DOM 计数，非 JSON 数据源
6. 防崩机制 → 项目有 `anti-crash.js` 兜底，`window.ZT_CRASH` 备用模式，修改时注意兼容

---

## 八、SEO 与部署

- 每个页面必须包含 `title`、`meta description`、`h1`
- URL 使用语义化路径：`/pdf/merge.html`，避免查询参数
- 保持 GitHub Pages 兼容性，路径区分大小写
- `CNAME` 文件绑定自定义域名 `zentools.xyz`

---

## 九、禁止事项

1. 私自修改 Logo 图形结构、渐变配色、字体样式
2. 主页面添加花哨全局动效、杂乱弹窗广告
3. 主站国内页面直接走纯境外 CDN 节点
4. 新增第三方字体/全局样式，破坏基础组件一致性
5. 篡改基础圆角、配色、栅格布局
6. 硬编码颜色值代替 CSS 变量
7. 正文使用粗度过重字体
