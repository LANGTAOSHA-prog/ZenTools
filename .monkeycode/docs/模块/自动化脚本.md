# 自动化脚本集

## 概述

ZenTools 使用一组 Python 3 脚本自动化常见的维护任务：生成工具页面、同步数据、校验 JSON、生成站点地图和压缩资源文件。

## 脚本列表

### _add_tool.py — 工具页面生成器

创建新工具所需的 HTML 页面、更新 `tools-data.json`、申请 Google Indexing 并重新生成站点地图。

```bash
python3 _add_tool.py --slug pdf-ocr --category "PDF工具" \
  --name-zh "PDF OCR" --name-en "PDF OCR" --name-ja "PDF OCR" --name-vi "PDF OCR" \
  --desc-zh "OCR文字提取" --desc-en "Extract text from PDF" \
  --desc-ja "PDFからテキスト抽出" --desc-vi "Trích xuất văn bản từ PDF" \
  --keywords "ocr pdf" [--ai-free] [--ai-reg] [--ai-chinese]
```

**生成内容**:
1. `/分类/slug.html` — 工具 HTML 页面（含四语言 ZT_PAGE 和完整页面结构）
2. 更新 `data/tools-data.json` 中 `tools` 数组
3. 调用 `_gen_sitemap.py` 重新生成站点地图
4. Google Indexing API 通知（若配置了 API Key）

### _add_tutorial.py — 教程页面生成器

```bash
python3 _add_tutorial.py --slug pdf-ocr-tutorial --category "PDF工具" \
  --title-zh "PDF OCR教程" --desc-zh "使用OCR提取文字" \
  --tool-url "/pdf/pdf-ocr.html"
```

### _add_guide.py — 指南/评测页面生成器

```bash
python3 _add_guide.py --slug pdf-tools-review --type review \
  --title-zh "PDF工具评测" --desc-zh "PDF工具横向对比" \
  --word-count 2500 --read-minutes 20
```

### _gen_sitemap.py — 站点地图生成器

遍历所有 `.html` 文件生成 `sitemap.xml`（约 710 个 URL）。

```bash
python3 _gen_sitemap.py
```

**特点**:
- 自动计算 `<lastmod>`（文件修改时间）
- 首页优先级 1.0，分类页 0.8，工具页 0.6
- 排除 `.html` 和 `.htaccess` 中的忽略文件
- 处理 `robots.txt` 中的 disallow 规则

### _check_json.py — JSON 数据校验器

校验 `data/tools-data.json` 及其它 JSON 文件的格式完整性。

```bash
python3 _check_json.py
```

**检查项**:
- JSON 格式是否可解析
- 必需字段是否存在（`name`, `slug`, `category`, `url`）
- 分类名称是否在有效列表中
- 重复 slug 检查

### _sync_tools_data_js.py — 数据同步器

将 `data/tools-data.json` 同步为 `assets/js/tools-data.js`，方便首页直接通过 `<script>` 加载。

```bash
python3 _sync_tools_data_js.py
```

**输出**: `assets/js/tools-data.js`，内容为 `var toolsDataJson = { ... }`;

### _minify_assets.py — 资源压缩器

压缩 `assets/js/` 和 `assets/css/` 下的源文件生成 `.min` 版本。

```bash
python3 _minify_assets.py
```

**压缩对象**:
- `tool-ui.js` → `tool-ui.min.js`
- `common-i18n.js` → `common-i18n.min.js`
- `anti-crash.js` → `anti-crash.min.js`
- `style.css` → `style.min.css`
- `tool-ui.css` → `tool-ui.min.css`

### _opt_index.py — 首页优化器

优化 `index.html` 结构，提取内联样式到独立块，精简冗余代码。

```bash
python3 _opt_index.py
```

## 注意事项

- 所有脚本均支持 `-h` / `--help` 查看详细用法
- 脚本只修改项目文件，不依赖数据库或外部 API
- 修改 JS/CSS 源文件后必须运行 `_minify_assets.py`
- 修改 `tools-data.json` 后必须运行 `_check_json.py` + `_sync_tools_data_js.py`
- 新增/删除 HTML 页面后必须运行 `_gen_sitemap.py`
