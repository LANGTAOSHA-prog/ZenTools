PDF Tools（命令行工具包）

本页面为 pdf_tools 命令行工具的入口，工具实现位于仓库 feat/pdf-tools/pdf_tools。

功能

  • 合并 PDF（merge）
  • 拆分 PDF（split）
  • 提取页面（extract）
  • 批量处理（batch）

快速开始

# 安装依赖
pip install -r pdf_tools/requirements.txt

# 生成示例 PDF
python pdf_tools/pdf_tools.py create-samples

# 合并示例
python pdf_tools/pdf_tools.py merge pdf_tools/samples/sample1.pdf pdf_tools/samples/sample2.pdf -o pdf_tools/out/merged.pdf

# 拆分示例
python pdf_tools/pdf_tools.py split pdf_tools/samples/sample2.pdf -d pdf_tools/out/split_sample2

# 提取页面示例
python pdf_tools/pdf_tools.py extract pdf_tools/samples/sample2.pdf 2 3 -o pdf_tools/out/extracted.pdf

# 批量合并 samples 目录下所有 PDF
python pdf_tools/pdf_tools.py batch --op merge --input pdf_tools/samples --out pdf_tools/out

一站式 PDF 转图片、图片转 PDF、页面编辑等操作，所有处理在浏览器本地完成，隐私安全。

需要处理PDF文档的办公人员、学生、行政文员、律师、教师及所有需要日常编辑和转换PDF文件的用户。

优点

  • 完全免费，无需注册即可使用
  • 浏览器本地处理，文件不会上传服务器
  • 支持批量操作，一次处理多个文件
  • 保持原始排版和格式不变

缺点

  • 超大PDF文件（超过200MB）处理速度较慢

常见问题

支持哪些PDF功能？
支持PDF合并、拆分、压缩、加密、解密、转图片、转Word、转文本、添加水印、删除页面、旋转页面、排序页面、OCR识别等全套PDF处理功能。

有文件大小限制吗？
单个PDF文件建议不超过 200MB，超大文件处理速度会较慢。对于数百页的PDF文档，建议分批处理。

处理安全吗？
完全安全。所有处理在浏览器本地完成，文件不会上传到任何服务器，确保文档隐私。
