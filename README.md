## 🛠️ 技术栈

- **纯前端** — HTML5 + CSS3 + Vanilla JavaScript
- **数据驱动** — 一套 JSON 数据驱动全站工具渲染

- **国际化** — 自定义 i18n 引擎，支持 4 种语言
- **无外部依赖** — 不依赖 React/Vue/jQuery 等框架，轻量快速
