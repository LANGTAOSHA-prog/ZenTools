## 功能概述

**免费 AI 模型聚合平台**是一个智能的 API 聚合工具，支持自动轮询多个免费大模型源，并在某个源故障时自动切换到备用源。无需注册、无需 API Key，开箱即用。

### 支持的模型

| 模型名称 | 类型 | 特点 |
|---------|------|------|
| Mistral 7B | 开源模型 | 轻量高效，适合对话任务 |
| Gemma 2 9B | Google 出品 | 多语言支持优秀 |
| Phi-3 Mini | Microsoft | 推理能力强，响应快 |

### 适用场景

- ✅ 快速测试不同大模型的回答质量
- ✅ 开发阶段的原型验证
- ✅ 学习 AI 模型的对话能力
- ✅ 临时性的问答需求
- ✅ 跨域限制下的 API 调试

## 核心特性

### 🔌 自动故障切换

系统会按顺序尝试每个 API 源，一旦某个源返回成功响应，立即停止后续尝试并显示结果。如果所有源都失败，会显示详细的错误信息。

**工作流程：**
```
用户提问 → 尝试源 1 → 成功？→ 显示结果
              ↓ 失败
         尝试源 2 → 成功？→ 显示结果
              ↓ 失败
         尝试源 3 → 成功？→ 显示结果
              ↓ 全部失败
         显示错误提示
```

### ⚡ 一键自动获取

页面加载后会自动发送示例问题，让你立即体验效果。无需手动操作即可看到各个模型的响应情况。

### 🔄 智能重试机制

如果当前请求失败，可以点击「重试」按钮重新发起请求，系统会使用上次的问题内容自动重试。

### 🎯 实时状态反馈

- **灰色圆点**：就绪状态
- **橙色脉冲**：正在尝试模型
- **绿色圆点**：请求成功
- **红色圆点**：请求失败

### 📋 模型列表展示

顶部会显示所有可用的模型名称，方便你了解当前配置的源。

## 配置说明

### 添加新的 API 源

编辑 `index.html` 中的 `SOURCES` 数组：

```javascript
const SOURCES = [
    {
        name: '模型名称',           // 显示名称
        url: 'API 地址',            // 完整的 API URL
        model: '模型标识符',        // 模型名称或 ID
        headers: {                 // 请求头 (可选)
            'Content-Type': 'application/json'
        }
    },
    // 添加更多...
];
```

### 自定义超时时间

默认超时时间为 15 秒，可以修改：

```javascript
const timeoutId = setTimeout(() => controller.abort(), 15000); // 改为 30000 表示 30 秒
```

### 调整请求顺序

默认情况下，OpenRouter 的源会被优先尝试。如果需要自定义顺序，可以直接调整 `SOURCES` 数组的顺序。

### 添加认证信息

如果某个 API 需要认证，可以在配置中添加：

```javascript
{
    name: 'My API',
    url: 'https://api.example.com/v1/chat',
    model: 'my-model',
    headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer YOUR_API_KEY'
    }
}
```

### 修改最大 token 数

默认 `max_tokens` 为 500，可以根据需要调整：

```javascript
const payload = {
    model: src.model,
    messages: [{ role: 'user', content: prompt }],
    max_tokens: 1000,  // 改为更大的值
    temperature: 0.7,
};
```

## 常见问题

### Q1: 为什么所有模型都显示失败？

**可能原因：**
1. 网络连接问题
2. API 服务暂时不可用
3. 免费额度已用完
4. 跨域限制被浏览器阻止

**解决方案：**
- 检查网络连接是否正常
- 稍后重试（免费服务可能有临时故障）
- 使用代理服务器或后端转发
- 查看浏览器控制台查看详细错误信息

### Q2: 如何添加自己的 API 源？

参考「配置说明」章节，在 `SOURCES` 数组中添加新的对象即可。确保你的 API 兼容 OpenAI 的格式。

### Q3: 为什么有些模型响应很慢？

免费服务通常没有性能保证，响应时间取决于：
- 当前服务器负载
- 网络延迟
- 模型复杂度

建议设置合理的超时时间（15-30 秒）。

### Q4: 可以并发请求所有模型吗？

当前实现是串行请求（一个接一个），这是为了避免：
- 短时间内产生大量请求
- 浪费免费额度
- 触发速率限制

如需并发，可以修改代码逻辑，但请注意上述风险。

### Q5: 支持中文提问吗？

是的！Mistral 7B、Gemma 2 9B、Phi-3 Mini 都支持中文。建议使用中文提问以获得更好的结果。

### Q6: 如何在生产环境使用？

**不建议直接将此页面用于生产环境**，因为：
- 免费服务不稳定
- 没有 SLA 保证
- 可能存在安全限制

生产环境建议使用商业 API 服务（如 OpenAI、Anthropic 等）。

## 故障排查

### 步骤 1: 检查浏览器控制台

打开开发者工具（F12），查看 Console 标签页的错误信息：

```
源 Mistral 7B (Free) 失败：NetworkError
源 Gemma 2 9B (Free) 失败：HTTP 429 Rate limit exceeded
```

### 步骤 2: 验证网络连接

```bash
# 测试是否能访问 OpenRouter
curl -I https://openrouter.ai/api/v1/chat/completions
```

### 步骤 3: 测试单个 API

使用 curl 直接测试某个 API：

```bash
curl -X POST "https://openrouter.ai/api/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mistralai/mistral-7b-instruct:free",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

### 步骤 4: 检查 CORS 设置

如果遇到跨域错误，可以使用以下方法解决：

**方案 A：使用浏览器插件**
- 安装 "Allow CORS" 扩展
- 临时启用以测试

**方案 B：使用代理服务器**
```javascript
// 使用反向代理
const proxyUrl = 'https://your-proxy.com/proxy';
const resp = await fetch(proxyUrl + src.url, {...});
```

**方案 C：后端转发**
创建一个简单的后端服务来转发请求。

### 步骤 5: 更新 API 源

如果某个源长期不可用，可以从配置中移除：

```javascript
const SOURCES = [
    // 保留可用的源
    { name: 'Mistral 7B', ... },
    // 移除不可用的源
];
```

## 技术细节

### 架构设计

```
┌─────────────────┐
│   用户界面       │
│  (HTML/CSS/JS)  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   请求控制器     │
│  (fetchWithFallback)│
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌─────────┐ ┌─────────┐
│  源 1    │ │  源 2    │
│(Mistral)│ │(Gemma)  │
└─────────┘ └─────────┘
```

### 关键函数说明

#### `fetchWithFallback(prompt)`

核心函数，负责轮询所有源并处理故障切换。

**参数：**
- `prompt`: 用户的输入问题

**返回值：**
- 成功：返回响应内容字符串
- 失败：返回 null

#### `setStatus(text, type)`

更新状态栏显示。

**参数：**
- `text`: 状态文本
- `type`: 状态类型 (`idle`, `loading`, `success`, `error`)

#### `renderBadge()`

渲染模型列表徽章。

## 最佳实践

### 1. 合理设置问题长度

避免过长的提问，建议控制在 500 字以内，以获得更快的响应。

### 2. 使用清晰的表达

明确的问题能获得更好的回答，例如：
- ❌ "解释一下"

### 4. 保存有用的回答

免费服务的可用性会变化，定期检查并更新配置。
