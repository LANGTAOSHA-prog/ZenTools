PDF 合并工具使用教程：三步合并多个 PDF 文件

📅 2026-06-18⏱ 3 分钟阅读
学会使用 ZenTools 在线 PDF 合并工具，无需安装软件，直接在浏览器中完成多个 PDF 文件的合并，保护你的文件隐私。
PDF合并
📖 点击展开详细教程

为什么要合并 PDF？

工作中经常遇到需要把多个 PDF 文件合并成一个的情况——比如将几份扫描合同合并归档、把多页课件整合成一份文档、或者把不同章节的报告拼接起来。使用 ZenTools 在线 PDF 合并工具，无需安装任何软件，在浏览器中即可完成。

打开工具

访问 PDF 合并工具，所有处理在浏览器本地完成，文件不会上传到任何服务器。

操作步骤

① 上传 PDF 文件

点击上传区域，从电脑中选择要合并的 PDF 文件。你可以一次选择多个文件，支持批量上传。文件顺序将作为合并后的页面顺序。

② 调整文件顺序

上传后，文件列表会按顺序显示。你可以拖拽列表中的文件来调整顺序，也可以点击文件的删除按钮移除不需要的文件。

③ 点击「合并」

确认文件顺序无误后，点击「合并 PDF」按钮。工具会立即在浏览器本地开始处理，几秒后即可完成合并。

④ 下载合并结果

合并完成后，点击「下载」按钮即可将合并后的 PDF 保存到本地。所有页面将按照你设定的顺序排列在一个文件中。

实用技巧

先排序再上传：在文件选择器中按住 Ctrl（Windows）或 Command（Mac）键，可以按你点击的顺序多选文件。上传后也可以通过拖拽微调顺序。
合并前先压缩：如果某个 PDF 文件特别大（超过 10MB），可以先使用 PDF 压缩工具 压缩后再合并，减少最终文件体积。

常见问题

Q：支持合并多少个 PDF？
A：没有严格限制，但建议一次合并不超过 20 个文件，总页数控制在 500 页以内，以保证处理速度。

Q：合并后文件质量会下降吗？
A：不会。合并过程不重新编码页面内容，只是将页面按顺序组装，质量完全保持不变。

Q：文件会被上传到服务器吗？
A：不会。所有处理在浏览器本地完成，文件不会离开你的电脑。

图片压缩教程：在线压缩 JPG 和 PNG 图片

📅 2026-06-18⏱ 2 分钟阅读
学会使用在线图片压缩工具，大幅减小图片文件体积，适合网页上传、邮件附件和存储优化。
图片压缩JPGPNG
📖 点击展开详细教程

为什么要压缩图片？

一张手机拍的照片动辄 3~5 MB，直接上传到网页或通过邮件发送，不仅加载慢，还可能超出附件大小限制。图片压缩可以在尽量保持视觉质量的前提下，大幅减小文件体积，让网页打开更快、邮件发送更顺畅、存储空间更充裕。

打开工具

访问 图片压缩工具，所有处理在浏览器本地完成，文件不会上传到任何服务器。

操作步骤

① 上传图片

点击「选择文件」按钮，从电脑中选择要压缩的 JPG、PNG 或 WebP 图片。你也可以直接拖拽图片到文件选择区域（如果浏览器支持）。

② 选择压缩质量

根据你的需求选择合适的压缩级别：

  • 高清压缩 90% — 画质几乎无损，适合摄影作品、设计稿等对画质要求高的场景。
  • 推荐压缩 75% — 平衡画质与体积，适合大多数网页配图和日常使用。
  • 强力压缩 55% — 体积明显减小，适合缩略图、预览图或对画质要求不高的场景。
  • 极限压缩 35% — 体积最小，适合做占位图或快速预览。

③ 点击「开始压缩」

工具会立即在浏览器本地对图片进行压缩处理。处理速度取决于图片大小，一般几秒内完成。

④ 预览效果

压缩完成后，下方会显示压缩前后的文件大小对比，同时展示压缩后的图片预览。你可以直观地判断画质是否满足要求。

⑤ 下载保存

如果对压缩结果满意，点击「下载图片」即可保存到本地。如果效果不理想，可以返回第②步调整压缩质量重新压缩。

实用技巧

批量压缩多张图片：如果你需要一次压缩多张图片，推荐使用 批量图片压缩工具，支持同时上传多张图片，并能打包为 ZIP 下载。
先压缩再上传：无论是做网站配图、发公众号文章还是邮件附件，建议先压缩再上传。一张压缩后的图片（100~300 KB）与原始图片（3~5 MB）在屏幕上肉眼几乎看不出差别，但加载速度可以提升 10 倍以上。
选择合适的格式：照片类内容用 JPG，图标/截图用 PNG，需要动图用 WebP。选择合适的格式本身就是一种"压缩"。

常见问题

Q：支持哪些图片格式？
A：支持 JPG、PNG、WebP 三种常见格式。

Q：压缩后图片质量会明显下降吗？
A：采用智能压缩算法，在推荐模式（75%）下，视觉质量几乎不受影响。你可以通过预览功能对比压缩前后的效果。

Q：支持批量压缩吗？
A：本工具支持单张压缩。如需批量处理多张图片，请使用 批量图片压缩工具。

Q：我的图片会上传到服务器吗？
A：不会。所有压缩处理都在你的浏览器本地完成，图片不会离开你的电脑。

视频转 GIF 教程：将视频片段转换为 GIF 动图

📅 2026-06-18⏱ 3 分钟阅读
将有趣的视频片段转换成 GIF 动图，用于社交媒体分享、产品展示和内容创作。
视频转GIF动图
📖 点击展开详细教程

为什么要将视频转成 GIF？

GIF 动图在社交媒体、聊天工具和博客文章中比视频更方便传播——无需点击播放就能自动展示内容，文件体积小，兼容性好。无论是展示产品操作步骤、分享有趣的瞬间，还是制作表情包，视频转 GIF 都是最常用的功能之一。

打开工具

访问 视频转 GIF 工具，所有处理在浏览器本地完成。

操作步骤

① 上传视频

点击上传区域，选择电脑中的 MP4、WebM、AVI 或 MOV 格式视频文件。建议选择时长较短（10 秒以内）的视频片段，GIF 文件大小与时长成正比。

② 选择片段范围

部分版本的工具支持选择视频的起始时间和结束时间。你可以拖动滑块或输入时间码，截取最精彩的一段。如果工具不支持选范围，可以先在本地用视频剪辑工具裁剪好片段。

③ 调整 GIF 参数

根据需要调整 GIF 的尺寸（宽度）和帧率（FPS）。建议：

  • 尺寸： 480px 宽适合聊天分享，320px 适合表情包，640px 适合博客配图
  • 帧率： 10 FPS 是常用值，15 FPS 更流畅但文件更大，5 FPS 文件最小

④ 点击「生成 GIF」

点击按钮开始转换。处理时间取决于视频时长、尺寸和帧率，一般几秒到几十秒。

⑤ 下载 GIF

转换完成后预览效果，如果满意点击「下载」保存到本地。如果不满意，调整参数重新生成。

实用技巧

控制文件大小：GIF 动图容易体积过大。如果生成的 GIF 超过 5MB，建议降低帧率或缩小尺寸。10 FPS + 480px 宽度是性价比最高的设置组合。
先裁剪视频：如果只需要视频中的一小段，建议先使用 视频裁剪工具 截取片段，再转成 GIF，可以节省大量处理时间。

常见问题

Q：支持哪些视频格式？
A：支持 MP4、WebM、AVI、MOV 等常见格式。

Q：生成的 GIF 太大怎么办？
A：尝试降低帧率（从 15 FPS 降到 10 FPS）或缩小输出尺寸（从 640px 降到 480px）。

Q：最长支持多长的视频？
A：建议不超过 30 秒。GIF 文件大小与时长成正比，过长的视频会导致文件太大。

AI 写作能做什么？

打开工具

访问 AI 写作工具，输入主题即可生成文章内容。

操作步骤

① 输入写作主题

在输入框中填写你的写作主题或要求。越具体越好：

  • ❌ 不好的输入：「写一篇文章」
  • ✅ 好的输入：「写一篇 800 字的公众号文章，主题是新手如何开始健身，面向办公室白领」

② 选择文章类型

③ 点击「生成」

④ 查看并修改

组合使用不同模式：先用「大纲」模式生成文章结构，确定框架后用「正文」模式分段落生成内容。这样比一次生成整篇文章更容易控制质量。
AI 是起点，不是终点：AI 生成的文字作为初稿，可以节省大量从零开始的时间。但最终的润色、校对和个性化调整还是需要你来完成。

Q：生成的内容会不会和别人重复？
A：AI 每次生成的内容都是基于你的输入实时生成的，具有独特性。但建议在使用前做适当修改和润色。

Q：支持生成英文内容吗？

JSON 格式化与校验教程

📅 2026-06-20⏱ 2 分钟阅读
学会使用在线 JSON 格式化工具，快速格式化、压缩和验证 JSON 数据，提高开发效率。
JSON开发工具
📖 点击展开详细教程

为什么要格式化 JSON？

JSON 是一种轻量级的数据交换格式，广泛用于 API 接口、配置文件和数据存储。从服务器获取或从文件读出的 JSON 通常是一行压缩格式，难以阅读和修改。JSON 格式化工具可以帮你把压缩的 JSON 变成结构清晰的层级文本，同时检查语法错误。

打开工具

访问 JSON 格式化工具，所有处理在浏览器本地完成，数据不会上传。

操作步骤

① 粘贴 JSON 数据

将从 API 返回、配置文件或代码中获取的 JSON 数据粘贴到输入框中。支持粘贴压缩格式（一行）或已经部分格式化的 JSON。

② 选择操作模式

工具提供几种操作模式：

  • 格式化（美化） — 将压缩的 JSON 展开为缩进清晰的层级结构
  • 压缩 — 将格式化的 JSON 压缩为一行，适合传输和存储
  • 校验 — 检查 JSON 语法是否正确，错误位置自动标红

③ 点击执行

选择模式后点击对应按钮，工具会立即处理。如果 JSON 有语法错误（如缺少逗号、引号不匹配），工具会高亮错误位置并提示原因。

④ 复制结果

处理完成后，点击「复制」按钮将结果复制到剪贴板，或直接在编辑器中使用。

实用技巧

先校验再使用：在调试 API 接口时，将返回的 JSON 先粘贴到校验工具检查语法，可以快速发现接口异常。错误信息会直接标明问题位置。
对比 JSON 差异：如果需要对比两个 JSON 的差异，可以使用 JSON Diff 对比工具，支持并排对比和结构化对比。

常见问题

Q：支持多大的 JSON？
A：建议在 5MB 以内。过大的 JSON 文件会导致浏览器处理变慢。

Q：JSON 校验能检查哪些错误？
A：能检查常见语法错误，如缺少逗号、引号不匹配、多余逗号、键值对格式错误等。

Q：数据会被上传吗？
A：不会。所有处理在浏览器本地完成。

📅 2026-06-20⏱ 3 分钟阅读
使用在线 PDF OCR 工具，识别扫描件和图片型 PDF 中的文字内容，支持中英文，无需安装软件。
OCR文字识别PDF
📖 点击展开详细教程

什么是 OCR？什么时候需要它？

OCR（光学字符识别）可以将图片或扫描件中的文字信息提取为可编辑的文本。当你拿到一份扫描版 PDF 或拍照的文档，发现无法选中、复制或搜索其中的文字时，OCR 工具就能派上用场——无论是扫描合同、纸质书籍还是课程讲义。

打开工具

访问 PDF OCR 工具，所有处理在浏览器本地完成，文件不会上传到服务器。

操作步骤

① 上传 PDF 或图片

点击上传区域，选择要识别的扫描件 PDF 或图片文件。支持常见的 PDF 格式及 JPG、PNG 等图片格式。

② 选择识别语言

根据文档内容选择对应的识别语言。支持中文、英文以及中英混合识别。选择正确的语言可以大幅提高识别准确率。

③ 点击「开始识别」

点击按钮开始 OCR 识别处理。处理时间取决于文档的页数和图片清晰度。清晰度越高、排版越规整的文档识别速度越快、准确率越高。

④ 预览并复制结果

识别完成后，结果区域会显示提取的文字内容。你可以预览识别效果，如果发现错误可以手动修正。点击「复制」按钮将文字复制到剪贴板，或直接下载为文本文件。

实用技巧

提高识别准确率：确保原始文档清晰、文字端正。如果扫描件倾斜，可以先使用图片校正工具调整方向。黑白的扫描件比彩色的识别效果更好。
图片 OCR 同样可用：如果只需要识别单张图片中的文字，可以使用 图片 OCR 工具，操作更快捷，无需上传为 PDF。

常见问题

Q：支持识别哪些语言？
A：支持中文、英文和中英混合内容的识别。

Q：识别准确率有多高？
A：在清晰、端正的文档上，识别准确率可达 95% 以上。模糊、倾斜或手写的内容准确率会有所下降。

Q：支持多页 PDF 吗？
A：支持，可以逐页识别多页扫描 PDF 的内容。

Q：文件会保存到服务器吗？
A：不会。所有处理在浏览器本地完成，文件不会离开你的电脑。
