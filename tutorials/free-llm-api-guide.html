一、免费 LLM API 生态概览

在 AI 大模型快速发展的今天，越来越多的开发者和企业开始提供免费的 LLM API 服务。这些免费 API 不仅降低了 AI 应用的开发门槛，也为个人开发者和学生提供了宝贵的学习资源。GitHub 上的开源项目 awesome-freellm-apis 整理了全球 134 个免费 LLM API，涵盖 30 家提供商、390+ 个模型，每天自动更新数据，是开发者获取免费 AI 能力的首选资源。

这些免费 API 通常支持 OpenAI 兼容的接口格式，这意味着你可以使用相同的代码调用不同的模型，大大降低了切换成本。无论是用于 AI 编程工具、文档生成、代码审查，还是日常的知识问答，免费 API 都能提供足够强大的支持。

1.1 awesome-freellm-apis 项目介绍

awesome-freellm-apis 是一个由社区维护的开源项目，收录了全球范围内的免费 LLM API 资源。项目的核心特点包括：

  • 每日自动更新：项目使用自动化脚本每天抓取最新的 API 信息，确保数据的时效性
  • 一键配置代码：每个 API 都提供了针对 Cursor、Claude Code、OpenClaw 等工具的预配置代码
  • 多语言支持：项目文档支持中文、英文等多种语言，方便全球开发者使用
  • 详细分类：按提供商、模型类型、使用限制等维度进行分类，方便快速查找

1.2 为什么选择免费 API

免费 LLM API 的价值远不止"省了 20 美元"那么简单。它的真正意义在于降低了 AI 切换成本。以前你被锁定在 Cursor 的 $20 订阅中不敢换工具，现在你可以同时使用 5 个模型做对比：Gemini 写代码快、DeepSeek 逻辑好、Qwen 中文强。免费让你有了选择权，这才是最大的利益。

此外，免费 API 还有以下优势：

  • 零成本试错：在学习和测试阶段，不需要担心 API 调用费用
  • 模型对比：可以同时使用多个模型，找到最适合自己需求的模型
  • 国内友好：DeepSeek、智谱 AI、硅基流动等国内 API 无需梯子，注册即用
  • 生产级质量：许多免费模型的质量已经接近付费模型，日常使用完全够用
重要提醒：免费 API 通常有速率限制，不适合高频调用或生产环境。开发测试、个人项目、学习场景才是它的主战场。当你的项目上了规模，自然会转向付费服务。

三、AI 编程工具接入配置

配置好免费 API 后，下一步就是将其接入到 AI 编程工具中。目前主流的 AI 编程工具都支持自定义 API 配置，以下是详细的配置教程。

3.1 Cursor 配置教程

打开 Cursor 设置

打开 Cursor，点击左下角的设置图标，或者使用快捷键 Ctrl + ,（Mac 上是 Cmd + ,）打开设置面板。

添加自定义模型

在设置面板中，找到「Models」或「API」选项，点击「Add Custom Provider」添加自定义模型提供商。

# Cursor 添加 Google Gemini 免费 API 配置示例

# 打开 Cursor Settings
# 路径：Settings → Models → Add Custom Provider

# 配置信息：
Base URL: https://generativelanguage.googleapis.com/v1beta/openai/
API Key: 你的 Gemini API Key（从 aistudio.google.com 获取）
Model: gemini-2.0-flash

# 配置完成后，在 Cursor 中选择该模型即可使用

验证配置

配置完成后，在 Cursor 的聊天面板中选择你刚刚添加的模型，发送一条测试消息，确认模型能够正常响应。

3.2 Claude Code 配置教程

编辑配置文件

Claude Code 使用配置文件来管理模型设置。配置文件通常位于项目根目录的 .claude/ 目录下。

# Claude Code 配置文件示例（.claude/config.json）

{
  "providers": [
    {
      "name": "gemini-free",
      "apiBase": "https://generativelanguage.googleapis.com/v1beta/openai/",
      "apiKey": "你的 Gemini API Key",
      "models": ["gemini-2.0-flash"]
    },
    {
      "name": "deepseek-free",
      "apiBase": "https://api.deepseek.com/v1",
      "apiKey": "你的 DeepSeek API Key",
      "models": ["deepseek-chat"]
    }
  ],
  "defaultProvider": "gemini-free"
}

使用自定义模型

配置完成后，在 Claude Code 中选择你添加的自定义模型即可。你也可以在命令行中指定模型：

# 使用自定义模型运行 Claude Code
claude --provider gemini-free "请帮我写一个 Python 函数"

# 或者在交互式模式中选择模型
claude
> 选择模型: gemini-free
> 输入你的问题...

四、Puter.js 零配置方案

如果你连注册 API Key 都嫌麻烦，还有一个更简单的方案——Puter.js。它是一个"用户付费"模式的免费 AI API 网关，支持 500+ 模型（GPT-5.4、Claude Sonnet 4.6、Gemini、DeepSeek 全有），不需要任何 API Key。

Puter.js 的工作原理是：用户通过 Puter 平台使用 AI 服务，Puter 向模型提供商付费，而用户只需要在 Puter 平台充值即可。对于开发者来说，这意味着你不需要管理多个 API Key，只需要一个 Puter 账号就能访问所有模型。

引入 Puter.js

在 HTML 文件中添加一行 script 标签即可使用：

<!-- 引入 Puter.js -->
<script src="https://js.puter.com/v2/"></script>

<script>
  // 调用 AI 模型
  puter.ai.chat("解释机器学习的基本概念", {
    model: "openai/gpt-5.4-nano"
  }).then(response => {
    console.log(response);
    puter.print(response);
  });
</script>

支持的模型

Puter.js 支持 500+ 模型，包括：

  • OpenAI 系列：GPT-5.4、GPT-4o、GPT-3.5
  • Claude 系列：Claude Sonnet 4.6、Claude Haiku
  • Gemini 系列：Gemini 2.0 Flash、Gemini 1.5 Pro
  • DeepSeek 系列：DeepSeek V3、DeepSeek R1
  • 开源模型：Llama、Qwen、Mistral 等

适用场景

Puter.js 适合以下场景：

  • 快速原型：几分钟内搭建一个 AI 应用原型
  • 前端 Demo：在前端项目中快速集成 AI 能力
  • 学习实验：学习 AI 开发，不需要管理复杂的 API 配置
  • 多模型对比：轻松切换不同模型，对比效果
⚠️ 注意事项

Puter.js 不适合高频调用场景。由于它是"用户付费"模式，每次调用都会产生费用（虽然很便宜）。如果你的应用需要大量调用 AI 模型，建议使用传统的 API Key 方式。

五、适用场景与注意事项

5.1 适合的场景

  • ✅ 个人项目开发测试：免费 API 完全够用，不需要担心费用
  • ✅ AI 编程工具白嫖：Cursor、Claude Code 接入免费模型，永久免费使用
  • ✅ 学习 AI 开发：不用充钱就能玩转多个模型，快速上手
  • ✅ 模型对比测试：同时用 5 个模型跑同一个 Prompt，看哪个效果最好
  • ✅ 文档生成：使用长上下文模型（如 Gemini 2M）处理大型文档

5.2 不太适合的场景

  • ⚠️ 生产环境高频调用：速率限制会让你怀疑人生，建议付费
  • ⚠️ 需要 SLA 保障的企业场景：免费的不保证可用性，可能随时调整
  • ⚠️ 处理敏感数据的场景：别把机密信息发到免费 API，注意数据安全
  • ⚠️ 需要稳定延迟的场景：免费 API 的延迟可能不稳定，不适合实时应用
💡 最佳实践建议

建议同时配置 2-3 个免费 API，作为备用方案。当某个 API 达到速率限制时，可以自动切换到另一个。这样可以最大化免费资源的使用效率，确保开发过程不受影响。

六、常见问题

问题 解答
免费 API 有使用限制吗？ 是的，大多数免费 API 有速率限制（如 15-30 次/分钟）和每日调用次数限制。具体限制请参考各提供商的官方文档。
需要信用卡注册吗？ Groq 不需要信用卡，Google Gemini 需要 Google 账号，DeepSeek 和智谱 AI 需要手机号注册。硅基流动需要邮箱注册。
国内能访问吗？ DeepSeek、智谱 AI、硅基流动可以直接访问。Groq 和 Google Gemini 可能需要网络工具。
API 格式兼容吗？ 大多数免费 API 都支持 OpenAI 兼容格式，这意味着你可以使用相同的代码调用不同模型。
数据安全吗？ 免费 API 的数据安全取决于提供商的政策。不要发送敏感信息，生产环境建议使用付费服务。
项目会持续更新吗？ awesome-freellm-apis 项目每天自动更新，确保数据的时效性。你也可以关注项目的 GitHub 仓库获取最新动态。
总结：免费 LLM API 是开发者降低 AI 使用门槛的重要工具。通过合理配置和使用，你可以让 AI 编程工具永久免费，同时保持高质量的开发体验。记住，免费的是获客手段，付费的是服务保障。等你项目上了规模，你会自动付费。但在此之前，白嫖是开发者的基本权利。
