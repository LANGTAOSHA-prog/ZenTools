    二、系统要求与准备工作

    最低系统配置

    Windows 用户
    • 操作系统：Windows 10 (64 位) 或更高版本
    • CPU：Intel Core i5-8400 或 AMD Ryzen 5 2600
    • 内存：16GB RAM（推荐 32GB）
    • 硬盘：至少 50GB 可用空间
    • 显卡：NVIDIA GTX 1060 6GB 或更高（可选）
    macOS 用户
    • 操作系统：macOS 12 (Monterey) 或更高版本
    • CPU：Apple M1 芯片或 Intel Core i7
    • 内存：16GB RAM（M1 以上推荐 32GB）
    • 硬盘：至少 50GB 可用空间
    • 显卡：集成 GPU 即可（M1 性能优异）
    Linux 用户
    • 操作系统：Ubuntu 20.04+ / Fedora 36+ / Debian 11+
    • CPU：Intel Core i5-8400 或 AMD Ryzen 5 2600
    • 内存：16GB RAM（推荐 32GB）
    • 硬盘：至少 50GB 可用空间
    • 显卡：NVIDIA GPU + CUDA 驱动（可选）

    三、下载与安装步骤

    方法一：官方渠道下载（推荐）

    步骤 1：访问官网

    打开浏览器访问 https://agnes-ai.com/download

    步骤 2：选择对应版本

    根据您的操作系统选择合适的安装包：

    • Windows：下载 AgnesDesktop-Windows-x64-v2.5.0.exe
    • macOS：下载 AgnesDesktop-macos-arm64-v2.5.0.dmg（M1/M2）或 AgnesDesktop-macos-x86_64-v2.5.0.dmg（Intel）
    • Linux：下载 AgnesDesktop-Linux-x64-v2.5.0.AppImage
    步骤 3：执行安装

    Windows:

    # 双击 exe 文件运行安装向导

# 勾选"创建桌面快捷方式"

    macOS:

    # 双击 dmg 文件挂载镜像
# 将 Agnes Desktop 图标拖拽到 Applications 文件夹
# 首次启动可能需要右键点击 → 打开（绕过 Gatekeeper）

    Linux:

    四、首次配置与模型下载

    初始设置向导

    首次启动 Agnes 桌面版时，会弹出设置向导：

    步骤 1：语言选择

    选择界面语言（推荐简体中文），点击"下一步"

    步骤 2：数据目录配置

    选择模型和缓存文件的存储位置：

    • 默认路径：
      • Windows: C:\Users\[用户名]\AppData\Roaming\AgnesDesktop
      • macOS: ~/Library/Application Support/AgnesDesktop
      • Linux: ~/.config/AgnesDesktop
    • 建议：如果 C 盘空间不足，建议选择其他分区（需预留至少 100GB）
    步骤 3：GPU 加速检测

    Agnes 会自动检测可用的 GPU 设备：

    • 检测到 NVIDIA GPU：自动启用 CUDA 加速
    • 检测到 Apple Silicon：自动启用 Metal 加速
    • 仅 CPU：使用纯 CPU 推理（速度较慢但可用）

    模型下载与管理

    进入主界面后，点击左侧「模型库」标签：

    可用模型列表：
✅ Qwen-Chat-7B-Instruct (轻量级，适合入门)
✅ Qwen-Chat-14B-Instruct (平衡型，推荐)
✅ Qwen-Max-30B (高性能，需要高端硬件)
✅ CodeLlama-13B-Python (编程专用)
✅ Mistral-7B (开源社区热门)
✅ Phi-3-mini (微软出品，效率高)
    下载步骤
    1. 点击目标模型右侧的「下载」按钮
    2. 选择下载质量（推荐：INT4 量化版，速度与精度平衡）
    3. 等待下载完成（根据网络速度，7B 约 5-15 分钟）
    4. 下载完成后自动切换到「已安装」标签

    {
  "memory": {

    "cache_enabled": true,        # 启用 KV Cache
    "quantize_weights": true      # 权重量化
  }
}

    七、常见问题与故障排查

    问题 1：启动失败

    症状：双击图标无反应或闪退

    解决方案：

    # Windows:
1. 以管理员身份运行
2. 检查是否安装了 WebView2 Runtime
3. 查看日志：C:\Users\[用户名]\AppData\Local\AgnesDesktop\logs\

# macOS:
1. 终端运行：open /Applications/Agnes\ Desktop.app
2. 查看控制台日志：Console.app → Agnes Desktop

# Linux:
1. 终端运行：./AgnesDesktop.AppImage --no-sandbox
2. 检查依赖：ldd AgnesDesktop.AppImage

    问题 2：模型加载失败

    症状：提示"Failed to load model"

    解决方案：

    1. 检查磁盘空间是否充足（至少 2 倍模型大小）
2. 重新下载模型文件
3. 验证模型完整性：
   设置 → 模型管理 → 点击模型右侧「验证」按钮
4. 尝试更换模型版本（如 INT4 → FP16）

    问题 3：响应速度慢

    症状：生成速度低于预期

    解决方案：

    1. 确认 GPU 加速已启用：设置 → 性能 → GPU 状态
2. 降低模型复杂度：切换到更小参数模型
3. 减少上下文长度：设置 → 最大上下文 → 改为 2048
4. 关闭其他占用 GPU 的程序（游戏、视频渲染等）
5. 更新显卡驱动至最新版本

    问题 4：内存溢出

    症状：提示"Out of memory"或程序崩溃

    解决方案：

    1. 立即停止当前对话
2. 重启 Agnes Desktop
3. 减小 batch_size 参数（settings.json）
4. 使用量化模型（INT8 或 INT4）
5. 增加系统虚拟内存（Windows：系统属性 → 高级 → 性能设置）

    问题 5：黑屏或界面异常

    解决方案：

    # 强制刷新界面
Ctrl + R

删除配置文件：
Windows: %APPDATA%\AgnesDesktop\settings.json
macOS: ~/Library/Application Support/AgnesDesktop/settings.json
Linux: ~/.config/AgnesDesktop/settings.json

# 重新启动程序（会自动生成新配置）

  "type": "qwen",

    将 Agnes 桌面版作为本地 API 服务器使用：

    自动化脚本集成

    #!/bin/bash
# agnes-batch.sh - 批量处理文本文件

for file in *.txt; do
  echo "Processing $file..."
  curl -X POST http://localhost:8080/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d "{\"model\": \"qwen-7b\", \"messages\": [{\"role\": \"user\", \"content\": '$(cat $file)'}]}" \
    > "${file%.txt}_response.json"
done

echo "Batch processing complete!"
