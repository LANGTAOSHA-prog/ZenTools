🚀 第二部分：我的实际操作步骤

步骤一：注册 Google AI Studio

  1. 访问官网：打开 https://aistudio.google.com/
  2. 登录账号：使用你的 Google 账号登录（如果没有，需要先注册一个 Gmail 账号）
  3. 同意条款：首次使用会要求同意服务条款和隐私政策
  4. 获取 API Key：点击左上角的"Get API key"按钮
💡 我的经验：注册过程非常顺利，全程中文界面，大约 2 分钟就搞定了。唯一需要注意的是，Google 可能会要求你进行手机号验证（这是为了防止滥用）。

⚠️ 第四部分：我遇到的坑与解决方案

坑 1：免费额度用完怎么办？

我的经历：用了大约一周后，我发现免费额度快用完了。每天大约有 60 次免费请求的限制，对于重度用户来说确实不够。

解决方案：

  1. 申请新的 Google 账号：每个新账号都有独立的免费额度
  2. 优化调用策略：缓存常用查询结果，减少重复请求
  3. 混合使用多个模型：简单任务用轻量模型，复杂任务再用 Gemini

坑 2：API Key 泄露风险

我的教训：一开始我把 API Key 写在了前端代码里，后来意识到这很危险。

正确做法：

❌ 错误示范（不要这样做）
// 前端代码中直接暴露 API Key const response = await fetch('https://api.example.com', { headers: { 'Authorization': 'Bearer YOUR_API_KEY' // 危险！ } });
✅ 正确做法（通过后端代理）
// 前端只发送请求给自家后端 const response = await fetch('/api/chat', { method: 'POST', body: JSON.stringify({ message: userMessage }) }); // 后端处理 API 调用 app.post('/api/chat', async (req, res) => { const geminiResponse = await callGeminiAPI(req.body.message); res.json(geminiResponse); });

坑 3：速率限制

Google 对免费用户有严格的速率限制（大约每分钟 15 次请求）。我的解决方案是：

🛠️ 添加请求限流中间件
const rateLimit = require('express-rate-limit'); const apiLimiter = rateLimit({ windowMs: 60 * 1000, // 1 分钟 max: 15, // 最多 15 次请求 message: '请求过于频繁，请稍后再试' }); app.use('/api/chat', apiLimiter);

当需要处理大量数据时，我采用了批量策略：

🔄 批量处理示例
async function batchProcess(items) { const results = []; for (const item of items) { try { const result = await processSingle(item); results.push(result); // 避免触发速率限制 await sleep(2000); } catch (error) { console.error('处理失败:', error); await sleep(5000); // 出错后等待更久 } } return results; }

3. 错误处理与重试机制

🔄 智能重试策略
async function callGeminiWithRetry(prompt, maxRetries = 3) { for (let i = 0; i < maxRetries; i++) { try { const response = await callGeminiAPI(prompt); return response; } catch (error) { if (error.status === 429 && i < maxRetries - 1) { // 速率限制，等待后重试 const waitTime = Math.pow(2, i) * 1000; console.log(`速率限制，等待 ${waitTime}ms 后重试...`); await sleep(waitTime); } else { throw error; } } } }

🔮 第七部分：常见问题解答 (FAQ)

Q1: 我真的不需要付钱吗？

A:是的，Google AI Studio 的免费层完全够用。即使超过免费额度，你也可以选择暂停使用，或者升级到付费版（按量计费，非常便宜）。

Q2: 免费额度和付费版有什么区别？

A:主要区别在于速率限制和并发请求数。免费版的响应速度和输出质量与付费版完全一致。

Q3: 我的数据会被用来训练模型吗？

A:根据 Google 的政策，通过 API 发送的数据不会被用于训练公开模型。但你仍应遵守隐私法规，避免上传敏感信息。

Q4: 如果我要做商业项目，可以用免费版吗？

A:可以，但需要注意免费层的速率限制。如果业务规模较大，建议升级到付费版以获得更好的服务保障。

Q5: Gemini 2.5 Flash 和完整版有什么区别？

A:Flash 版本主打速度和效率，适合大多数日常任务。完整版更适合需要深度推理的复杂场景。对于 90% 的使用场景，Flash 版本已经足够强大。
