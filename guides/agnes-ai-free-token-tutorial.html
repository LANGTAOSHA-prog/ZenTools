    三、API Key 配置详解

    环境配置方式

    # Linux/Mac
export AGNES_API_KEY="anes_xxxxxxxxxxxxxxxxxxxxxxxx"

# Windows (PowerShell)
$env:AGNES_API_KEY="anes_xxxxxxxxxxxxxxxxxxxxxxxx"

# Docker 环境变量
docker run -e AGNES_API_KEY=anes_xxx your-image

    请求头配置

    所有 Agnes API 请求都需要在 Header 中携带 Authorization：

    Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
X-Client-Version: 1.0.0

    基础请求结构

    POST https://api.agnes-ai.com/v1/image/generate
Content-Type: application/json
Authorization: Bearer anes_xxx

{
  "model": "stable-diffusion-xl-v1.0",
  "prompt": "A beautiful sunset over the ocean",
  "negative_prompt": "blurry, low quality",
  "num_inference_steps": 50,
  "guidance_scale": 7.5,
  "width": 1024,
  "height": 1024,
  "num_images": 1
}
    注意事项：
    • API Key 必须通过 HTTPS 传输，禁止明文传输
    • 每个请求消耗 1-5 个 Token（取决于分辨率和步数）
    • 超出免费额度后会自动停止服务，不会扣费

    四、SDK 集成实战

    Python SDK 安装

    pip install agnes-ai-sdk

# 或者从 PyPI 安装最新版
pip install --upgrade agnes-ai-sdk

    基本使用示例

    import os
from agnes_ai import AgnesClient

# 初始化客户端
client = AgnesClient(
    api_key=os.getenv("AGNES_API_KEY")
)

# 简单文本生成图像
response = client.images.generate(
    model="stable-diffusion-xl-v1.0",
    prompt="A futuristic city with flying cars at night",
    size="1024x1024",
    n=1
)

# 保存生成的图像
with open("generated_image.png", "wb") as f:
    f.write(response.data[0].bytes)

    高级用法：批量处理

    prompts = [
    "Cyberpunk street scene with neon lights",

for prompt in prompts:
