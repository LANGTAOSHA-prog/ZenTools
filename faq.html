常见问题

PDF 报错、图片格式、浏览器兼容……这里整理了最常见的问题与排查办法。

📄常见 PDF 报错

❓PDF 文件打不开 / 提示“文件已损坏或格式错误”？▼
多为下载不完整或扩展名错误：
① 重新下载，确认文件完整；
② 检查扩展名是否为 .pdf（有时会变成 .pdf.pdf 重复）；
③ 用 PDF 修复 / 重组 类工具尝试恢复；
④ 确认对方发送的是真正的 PDF，而非把图片直接改了后缀。
❓PDF 打开后文字是乱码 / 方块？▼
通常是字体未嵌入或被替换：
① 让发送方用“打印到 PDF”重新生成，并勾选“嵌入所有字体”；
② 本机安装缺失字体（如宋体 / 思源）；
③ 若是图片型 PDF，用 OCR 文字识别 工具转成可选中文字。
❓PDF 提示“已加密，无法编辑 / 打印 / 复制”？▼
该文件设有权限密码或打开密码：
① 若你知道密码，用 PDF 去密码 工具移除限制（需先输入原密码）；
② 仅忘记打开密码且文件敏感，请联系作者获取；
③ 切勿使用来路不明的破解工具，有泄露风险。
❓PDF 太大，无法作为邮件附件 / 超过上传限制？▼
① 用 PDF 压缩 把图片型 PDF 压到可接受体积；
② 用 PDF 拆分 按章节拆成多个小文件分别发送；
③ 若含高清图片，先压缩图片再合并。
❓合并多个 PDF 后顺序错乱 / 页面丢失？▼
① 在 PDF 合并 工具里手动拖拽调整页面顺序再合并；
② 确认源文件没有损坏页；
③ 合并后预览检查页码连续性，缺失页用 PDF 提取页面 补回。

🖼️图片格式问题

❓PNG 和 JPG 该选哪个？▼
JPG 适合照片类（有损压缩、体积小）；PNG 适合图标 / 线条图 / 需要透明背景（无损、支持透明）。
截图发群聊选 PNG 更清晰；相册照片选 JPG 更省空间。
❓透明背景导出后变黑 / 变白？▼
透明通道在 JPG 中不被支持，导出为 JPG 时会用白（或黑）填充透明区。
需要保留透明请用 PNG / WebP / GIF；用 图片去背景 工具时务必选择输出 PNG。
❓上传图片提示“格式不支持 / 无法预览”？▼
① 旧系统常不支持 WebP / HEIC / AVIF，先转成通用 JPG / PNG；
② 确认文件没损坏、扩展名与真实格式一致；
③ 用 图片格式转换 工具统一成目标平台要求的格式。
❓图片体积太大 / 太模糊？▼
太大 → 用 图片压缩 减小体积（适度，过度会糊）；
太模糊 → 普通放大会更糊，需用 AI 图片放大 / 超分辨率 类工具做智能增强，而非简单拉伸。
❓GIF 不动 / 体积过大？▼
① 确认用支持动图的方式打开（部分预览只显示首帧）；
② 体积大 → 减少帧数、缩小尺寸，用 GIF 压缩 或转成 MP4 视频 更省空间。

🌐浏览器兼容问题

❓工具在 Safari / 旧版浏览器打不开或报错？▼
本站工具基于现代 JavaScript（ES2020+）与浏览器本地 API，建议使用 Chrome / Edge / Firefox 的新版本。
旧版 Safari 或 IE 可能不支持部分特性，请升级浏览器。
❓点“选择文件 / 拖拽”没反应？▼
① 确认浏览器未禁用 JavaScript；
② 部分功能需在 HTTPS 或 localhost 下运行，用 file:// 直接打开个别页面可能受限；
③ 尝试刷新或换用 Chrome / Edge。
❓处理大文件时卡顿 / 标签页崩溃？▼
浏览器有内存上限：
① 大文件分批处理，勿一次拖入几十个；
② 处理前关闭其他占用内存的标签页；
③ 优先使用标注“本地处理”的工具，数据不离开设备也更省网络。
❓手机上布局错乱 / 按钮点不到？▼
① 本站为响应式设计，建议用手机版 Chrome / Safari 并横屏或放大查看；
② 清理浏览器缓存后重试；
③ 可“添加到主屏幕”以 PWA 方式获得更接近原生的体验。
❓收藏 / 最近使用记录丢了？▼
这些记录仅保存在当前浏览器的本地存储（localStorage），更换浏览器、清理缓存或无痕模式都会使其消失。
重要工具建议手动加入书签。
