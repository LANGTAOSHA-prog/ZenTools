ZenTools 2.0 开发守则（ZT-DCA v1.0）
=====================================

正式名称：ZenTools 数据驱动分类架构
英文名称：ZenTools Data-Driven Category Architecture
简称：ZT-DCA

一、核心原则
------------
1. 数据驱动优先
- 所有工具信息统一存储于 /data/tools-data.json
- 首页、分类页、搜索页均从同一数据源读取
- 禁止多处重复维护工具列表

2. 单一数据源
- tools-data.json 为唯一工具数据源
- 新增工具优先修改 JSON，而非首页代码

3. 单工具单页面
- 每个工具独立 HTML 页面
- 示例：
  /pdf/merge.html
  /pdf/split.html
  /image/compress.html

二、标准目录结构
----------------
/
├─ index.html
├─ data/
│  └─ tools-data.json
├─ pdf/
├─ image/
├─ json/
├─ text/
├─ ai/
├─ developer/
├─ tutorials/
├─ assets/
│  ├─ css/
│  ├─ js/
│  ├─ images/
│  └─ icons/
├─ locales/
└─ sitemap.xml

三、工具数据规范
----------------
每个工具建议包含：
- name
- slug
- category
- url
- icon
- description

推荐扩展字段：
- featured
- new
- keywords

四、首页规范
------------
首页职责：
- 展示工具
- 搜索工具
- 推荐工具
- 分类导航

推荐结构：
Hero
↓
搜索框
↓
热门工具
↓
分类工具
↓
最新工具
↓
教程入口
↓
Footer

五、分类页规范
--------------
分类页统一放置于对应目录：
/pdf/index.html
/image/index.html
/json/index.html

分类页工具数据来自 tools-data.json。

六、多语言规范
--------------
所有新增页面默认支持多语言。

推荐结构：
/locales/zh/
/locales/en/
/locales/ja/

统一使用：
- common-i18n.js
- common.json
- 页面专用 JSON

七、工具开发规范
----------------
优先采用：
- HTML
- CSS
- JavaScript

目标：
- 浏览器本地运行
- GitHub Pages 直接部署
- Cloudflare Pages 直接部署
- Vercel 直接部署

尽量避免服务器依赖。

八、UI规范
-----------
统一风格：
- 深色主题优先
- 现代卡片式设计
- 响应式布局
- 移动端优先

工具卡推荐包含：
- 图标
- 名称
- 描述
- 进入按钮

九、SEO规范
------------
每个页面必须包含：
- title
- meta description
- h1

推荐 URL：
/pdf/merge.html

避免：
/tool?id=123

十、扩展规范
-------------
新增工具流程：
1. 创建工具页面
2. 更新 tools-data.json
3. 自动出现在首页、分类页、搜索页

无需修改首页核心代码。

十一、ZenTools 项目专属规则
---------------------------
1. 保持 ZenTools 2.0 当前首页稳定
2. 教程统一放入 tutorials 目录
3. 所有新页面默认支持多语言
4. 分类目录结构长期保持稳定
5. tools-data.json 为核心数据源
6. 支持未来搜索、筛选、收藏、工具对比功能扩展
7. 保持 GitHub Pages 兼容性

十二、更新日志自动维护规范
--------------------------
更新日志由 GitHub Actions（deploy.yml）在每次推送 main 时自动同步，人工无需维护 changelog.html（它读取 data/site-info.json 渲染）。

1. 新工具上线（自动记录一次）
- 在 data/tools-data.json 对应工具加 "new": true
- 推送后自动将该工具写入更新日志（中/英/日/越四语）
- 记录后系统自动把该工具标记的 new 置为 false（fire-once），不会重复记录
- tools-data.json 是单一数据源，新增工具优先改 JSON，不要直接改页面代码

2. 其他内容更新（改版 / 修 bug / 上新功能）
- 在 commit 消息写一行：cl:一句话说明
- 示例：cl:首页新增暗色模式切换
- 推送后自动追加为四语日志条目

3. 约束
- 不要手动编辑 data/site-info.json 的 changelog 数组（会被自动流程覆盖或重复追加）
- 日志按推送日期聚合到当日条目；跨日更新自动新建条目

十三、品牌开发守则（V1.0）
--------------------------------------------
本规范为 ZenTools 全平台品牌统一标准，适用于官网前端、小程序、安卓 APP、文档、PPT、公众号、GitHub、CDN/Worker 页面、宣传物料及后续所有迭代开发。以下为《ZenTools 品牌开发守则 V1.0》全文，作为本开发守则的品牌统一标准执行。

========== 品牌开发守则 V1.0 开始 ==========

# ZenTools 品牌开发守则 V1.0

## 总则
### 1. 品牌定位
ZenTools：**隐私优先、免费全能的本地在线工具平台**
核心调性：干净极简、专业可靠、高效易用、科技柔和，拒绝花哨冗余设计，保障跨平台视觉一致性，兼顾国内合规访问与全球访问体验。
适用范围：官网前端、小程序、安卓APP、文档、PPT、公众号、GitHub、CDN/Worker页面、宣传物料、后续所有迭代开发

### 2. 核心原则
- ✅ 统一性：严格遵循本规范，禁止私自修改Logo形态、主色、字体、圆角、基础组件样式
- ✅ 隐私优先：核心文案强调本地处理、数据不上传服务器
- ✅ 可访问性：兼顾浅色/暗黑模式、适配移动端、保证文字对比度达标
- ✅ 合规性：国内主站使用备案服务器，遵循ICP/公安备案监管；海外节点仅做CDN加速，不改动基础UI规范
- ✅ 性能原则：保持页面轻量化，不引入多余重样式、动画

---

## 一、Logo 使用规范
### 1. Logo基础版本
- **横版主Logo**：∞Z 图形 + ZenTools 标准字体 + 标语（主站顶部、导航栏、官网页脚、公众号头部）
- **竖版Logo**：∞Z 图形在上，ZenTools文字在下（宣传页、PPT封面）
- **纯Icon版本**：独立∞Z无限符号图标（浏览器favicon、App图标、小程序图标、头像）
- **单色版本**：纯黑版 / 纯白反白版（深色背景、印刷物料）
- ❌ 禁止：拉伸变形、修改线条结构、改动渐变配色、增加额外装饰、替换字体、裁剪图形核心结构

### 2. Logo安全留白
- 留白距离 = **图标高度的 1/4**，四周统一预留，禁止任何文字/按钮/元素侵入留白区域
- 禁止多个Logo紧贴排布，保持独立呼吸空间

### 3. Logo最小尺寸
- 网页端：横版Logo最小高度 `32px`，纯Icon最小 `24px`
- 移动端：纯Icon不小于 `48px`，保证清晰识别
- 印刷物料：不小于 15mm 高度
- 平台头像：
    - App Icon：1024×1024px（iOS/安卓标准）
    - 微信小程序图标：1080×1080px
    - GitHub Avatar：512×512px
    - Cloudflare Worker图标：512×512px

### 4. 背景适配规则
- 浅色模式：原版蓝青渐变Logo
- 暗黑模式：纯白反白Logo / 适配柔和渐变版本
- 纯色底色：优先使用单色版Logo，避免渐变冲突

## 二、品牌色规范
### 1. 主色
- 主蓝：`#0066FF`
- 科技青：`#00C2B8`
- 渐变组合：`linear-gradient(135deg, #0066FF, #00C2B8)`
### 2. 辅助色
- 成功绿：`#22C55E`
- 警告橙：`#F97316`
- 错误红：`#EF4444`
### 3. 中性色（浅色模式）
- 正文：`#111827`
- 次要文字：`#4B5563`
- 占位文字：`#9CA3AF`
- 背景底色：`#F9FAFB`
- 卡片底色：`#FFFFFF`
- 边框：`#E5E7EB`
### 4. 暗黑模式中性色
- 正文：`#F9FAFB`
- 次要文字：`#D1D5DB`
- 背景底色：`#0F172A`
- 卡片底色：`#1E293B`
- 边框：`#334155`
### 5. 基础规范
- 全局CSS变量定义颜色，统一调用，禁止新增自定义主色调
- 正文文字对比度 ≥ 4.5:1，保障无障碍访问
- 渐变仅用于品牌Logo、主按钮、首页标题区域，正文页面尽量用纯色减少性能消耗

---

## 三、字体规范
### 1. 中文字体
- 标题：**思源黑体 / Inter 中文版**，粗重：600 / 700
- 正文：**思源黑体 / 系统无衬线字体（PingFang SC, Microsoft YaHei）**，粗重：400 / 500
### 2. 英文/数字字体
- 标题/Logo英文：**Inter**
- 正文英文：**Inter / 系统默认无衬线字体**
### 3. 字号层级（网页端基准）
- H1 主标题：32px
- H2 板块标题：24px
- H3 卡片标题：18px
- 正文：16px
- 辅助小字：14px
- 说明备注：12px
### 4. 行高
- 标题行高：1.2
- 正文行高：1.5
### 5. 禁止
- 随意引入花式艺术字体、衬线字体，破坏整体极简风格
- 正文使用粗度过重字体

---

## 四、图标规范
1. 基础风格：**2px 线性图标，圆角 4px，整体 24px 网格对齐**，统一线条粗细
    - 主导航：线性图标
    - 功能卡片：可搭配轻量面性图标，保持同一套图标库
    - 禁止混搭粗线条、卡通、写实风格图标
2. 颜色：默认次要文字色，可hover时切换为主色
3. 暗黑模式：适配暗黑中性色，保证可见度
4. 工具图标：保持简洁功能示意，不添加多余光影特效

---

## 五、UI组件规范
### 1. 圆角基准
- 全局基准圆角：**12px**
    - 大卡片：16px
    - 按钮/输入框：8px
    - 小标签：6px
    - 禁止混用超大圆角/直角样式
### 2. 按钮规范
- **主按钮**：主色渐变底色、白色文字、圆角8px、padding: 12px 24px；hover轻微加深/柔和上浮动效
- **次要按钮**：白色底色+主色边框、主色文字
- **幽灵按钮**：透明底色、主色文字、hover背景浅主色
- 禁用态：降低透明度至40%，禁止交互
- 全局统一按钮样式组件（如Vue/React组件），禁止手写独立样式
### 3. 卡片规范
- 默认圆角16px，细微柔和阴影，浅色白底 / 深色模式深色卡片底色
- 卡片内间距：20px
- 工具卡片布局统一：图标+标题+简介结构，保持布局对齐
- 禁止随意修改卡片阴影、边框样式
### 4. 表单/输入框
- 圆角8px，统一边框样式，聚焦时主色高亮边框
- 保持全局表单样式组件复用

## 六、暗黑模式规范
1. 切换规则：跟随系统设置 + 手动切换按钮，存储用户偏好
2. 布局结构：与浅色版布局完全一致，仅替换配色方案，不改动排版、组件结构
3. Logo：使用纯白反白版/适配暗模式渐变版
4. 基础样式：
    - 背景：`#0F172A`
    - 卡片：`#1E293B`
    - 文字：浅色正文色
    - 主按钮：适配暗模式渐变/纯色版本
5. 校验：保证所有功能按钮、文字、图标在暗黑模式下可正常识别、无障碍访问

## 七、页面布局 & Banner 规范
### 1. 官网布局
- 整体居中布局，最大宽度 1200px，保持固定栅格系统
- 导航栏固定顶部，左侧ZenTools主Logo，右侧功能入口
- 首页Banner：16:9版式，居中主Logo+标语，极简背景，禁止复杂背景干扰阅读
    - 标语：标准版「专业在线工具平台 · 免费 · 高效 · 安全」
    - 备选版：「专业工具 · 无限可能 | Professional Tools For Everyone」
### 2. 公众号封面
- 标准尺寸：900 × 383px，左上角放置ZenTools横版Logo，预留标题区域，底色使用主色渐变/极简浅底色
### 3. PPT模板
- 16:9版式
    - 封面页：居中竖版/横版ZenTools Logo，主品牌底色
    - 内页：左上角小版Logo，正文遵循字体/配色规范
    - 数据页：保持统一图表配色，仅使用品牌基础色
### 4. 插画规范
- 风格：简约扁平几何科技插画，柔和渐变，以主蓝+科技青为主色调，不使用复杂3D/写实插画
- 核心表达：本地运算、隐私安全、高效工具、极简体验
- 禁止：复杂噪点、强霓虹光效、卡通拟人插画
