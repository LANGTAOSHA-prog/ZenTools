ZenTools 2.0 开发守则（ZT-DCA v1.0）
=====================================

正式名称：ZenTools 数据驱动分类架构
英文名称：ZenTools Data-Driven Category Architecture
简称：ZT-DCA

一、核心原则
------------
1. 数据驱动优先
- 所有工具信息统一存储于 /data/tools-data.json
- 首页、分类页、搜索页均从同一数据源读取
- 禁止多处重复维护工具列表

2. 单一数据源
- tools-data.json 为唯一工具数据源
- 新增工具优先修改 JSON，而非首页代码

3. 单工具单页面
- 每个工具独立 HTML 页面
- 示例：
  /pdf/merge.html
  /pdf/split.html
  /image/compress.html

二、标准目录结构
----------------
/
├─ index.html
├─ data/
│  └─ tools-data.json
├─ pdf/
├─ image/
├─ json/
├─ text/
├─ ai/
├─ developer/
├─ tutorials/
├─ assets/
│  ├─ css/
│  ├─ js/
│  ├─ images/
│  └─ icons/
├─ locales/
└─ sitemap.xml

三、工具数据规范
----------------
每个工具建议包含：
- name
- slug
- category
- url
- icon
- description

推荐扩展字段：
- featured
- new
- keywords

四、首页规范
------------
首页职责：
- 展示工具
- 搜索工具
- 推荐工具
- 分类导航

推荐结构：
Hero
↓
搜索框
↓
热门工具
↓
分类工具
↓
最新工具
↓
教程入口
↓
Footer

五、分类页规范
--------------
分类页统一放置于对应目录：
/pdf/index.html
/image/index.html
/json/index.html

分类页工具数据来自 tools-data.json。

六、多语言规范
--------------
所有新增页面默认支持多语言。

推荐结构：
/locales/zh/
/locales/en/
/locales/ja/

统一使用：
- i18n.js
- common.json
- 页面专用 JSON

七、工具开发规范
----------------
优先采用：
- HTML
- CSS
- JavaScript

目标：
- 浏览器本地运行
- GitHub Pages 直接部署
- Cloudflare Pages 直接部署
- Vercel 直接部署

尽量避免服务器依赖。

八、UI规范
-----------
统一风格：
- 深色主题优先
- 现代卡片式设计
- 响应式布局
- 移动端优先

工具卡推荐包含：
- 图标
- 名称
- 描述
- 进入按钮

九、SEO规范
------------
每个页面必须包含：
- title
- meta description
- h1

推荐 URL：
/pdf/merge.html

避免：
/tool?id=123

十、扩展规范
-------------
新增工具流程：
1. 创建工具页面
2. 更新 tools-data.json
3. 自动出现在首页、分类页、搜索页

无需修改首页核心代码。

十一、ZenTools 项目专属规则
---------------------------
1. 保持 ZenTools 2.0 当前首页稳定
2. 教程统一放入 tutorials 目录
3. 所有新页面默认支持多语言
4. 分类目录结构长期保持稳定
5. tools-data.json 为核心数据源
6. 支持未来搜索、筛选、收藏、工具对比功能扩展
7. 保持 GitHub Pages 兼容性

最终原则
--------
ZT-DCA = 数据驱动 + 分类管理 + 单工具页面 + 多语言支持 + SEO友好 + 本地运行优先。
