常见问题

工具无法正常使用怎么办？

请尝试刷新页面或更换浏览器（推荐使用最新版 Chrome、Edge 或 Firefox）。如果问题仍然存在，请通过邮件或 GitHub Issue 向我们反馈。

我的文件会上传到服务器吗？

不会。所有工具均在您的浏览器本地运行，文件不会上传到任何服务器。

网站支持哪些浏览器？

推荐使用最新版 Chrome、Edge、Firefox 或 Safari。部分工具需要浏览器支持相关 Web API。

你们会添加新工具吗？

会的！本站持续更新中。如果您有工具需求建议，欢迎通过邮件告诉我们。
