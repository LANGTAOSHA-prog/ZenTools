常见问题

工具无法正常使用怎么办？

请尝试刷新页面或更换浏览器（推荐使用最新版 Chrome、Edge 或 Firefox）。如果问题仍然存在，请通过邮件或 GitHub Issue 向我们反馈。

我的文件会上传到服务器吗？

不会。所有工具均在您的浏览器本地运行，文件不会上传到任何服务器，您可以放心使用。

网站支持哪些浏览器？

推荐使用最新版 Chrome、Edge、Firefox 或 Safari。部分工具（如录音、摄像头测试）需要浏览器支持相关 Web API。

如何反馈工具使用中遇到的问题？

您可以通过邮件联系我们，或在 GitHub 仓库提交 Issue。请尽量详细描述问题，包括使用的工具名称、浏览器版本和操作步骤。

你们会添加新工具吗？

会的！本站持续更新中。如果您有工具需求建议，欢迎通过邮件或 Issue 告诉我们。
