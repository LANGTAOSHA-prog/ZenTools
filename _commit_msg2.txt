fix: critical tool-ui.min.js syntax error preventing language switch

Root cause: Google Analytics URL "https://..." in minified JS had the "//"
incorrectly treated as a comment during minification, causing a syntax error
that prevented the entire IIFE (including initLang and ZT.applyLanguage) from
executing. The language dropdown change listener was never registered.

Fixes:
- tool-ui.min.js: split URL as 'https:'+'/...' to prevent // comment issue
- tool-ui.js: same fix in source to prevent recurrence
- Index.html: removed meaningless data-i18n from <br> element
- Index.html: renderHome dedup - remove old fav-section before re-insert
- Index.html: zt-langchange handler now also updates search placeholder
- Index.html: mobile drawer i18n reapply scoped to mobileTools only
- Index.html: removed redundant langSelect change listener
- tool-ui.js: ZT.applyLanguage now supports data-i18n-placeholder
